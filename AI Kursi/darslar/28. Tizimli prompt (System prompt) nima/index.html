  • Mavzu

    Dars maqsadi: Tizimli ko'rsatmalar, maxsus yordamchilar va API qanday ishlashini tushunish.

    Asosiy faoliyat: Maxsus yordamchi (Custom GPT, Claude Project yoki Gem) yaratish va API namunasini ko'rish.

    Davomiyligi: 45 daqiqa · Dushanba

    Tizimli prompt nima?

    System prompt — AIning butun suhbat davomidagi xulq-atvorini belgilaydigan doimiy ko'rsatma: kim ekani, qanday javob berishi, nimani qilmasligi.

    Sen "Matematika do'sti" nomli yordamchisan.
- 6-sinf o'quvchilari bilan gaplashasan.
- Hech qachon to'g'ridan-to'g'ri javob bermaysan, savollar bilan yo'naltirasan.
- Har javob 5 jumladan oshmaydi.
- Mavzudan tashqari savollarga muloyimlik bilan rad javobini berasan.

    Qayerda ishlatiladi?

    • Maxsus yordamchilar: ChatGPT'da Custom GPT, Claude'da Project, Gemini'da Gem — ko'rsatma va fayllar bilan o'z yordamchingizni yaratish.
    • Shaxsiy sozlamalar: «Custom instructions» — har suhbatda hisobga olinadi.
    • API — dasturchilar AIni o'z ilovasiga ulaydi; system prompt ilova uchun qoidalarni belgilaydi.
    API namunasi (tushunish uchun):
system: "Sen qisqa javob beradigan geografiya yordamchisisan."
user:   "Eng uzun daryo qaysi?"

  • Amaliyot

    Har bir topshiriqni AI vositasi bilan bajaring va natijani AI jurnaliga yozing. Shaxsiy ma'lumot kiritmang.

    1. Tuzilma

      Tizimli promptning 4 qismini (kim, kim bilan, qoidalar, cheklovlar) yozing.

    2. Oddiy va tizimli

      Bitta savolni oddiy chatda va «Matematika do'sti» ko'rsatmasi bilan so'rang. Farqni yozing.

    3. Qoida sinovi

      Yordamchiga mavzudan tashqari savol bering — qoidaga amal qildimi?

    4. O'z yordamchingiz

      O'qituvchi akkauntida bitta fan uchun maxsus yordamchi yarating (Custom GPT, Claude Project yoki Gem).

    5. Fayl qo'shish

      Yordamchiga konspekt yoki darslik bo'limini fayl qilib qo'shing va undan savol bering.

    6. Sinab ko'rish

      Sinfdoshingiz yordamchingizni 5 ta savol bilan sinasin va xato joylarni yozsin.

    7. Takomillashtirish

      Sinov natijalariga ko'ra tizimli promptni 2 marta yaxshilang.

    8. API namunasi

      O'qituvchi ko'rsatgan API namunasida system va user xabarlari farqini tushuntiring.

  • Uyga vazifa

    Barcha topshiriqlarni ketma-ket bajaring. Oxirgi topshiriqlar qo'shimcha ball uchun.

    1. Ko'rsatma yozish

      Ingliz tili mashqi uchun yordamchining tizimli promptini yozing.

    2. AI jurnali

      Maxsus yordamchi yaratish tajribangizni yozing.

    3. Custom instructions

      O'zingiz uchun shaxsiy ko'rsatmalar matnini yozing (shaxsiy ma'lumotsiz): qanday javob kerak, qanday uslubda.

    4. Qoidalar

      Bolalar uchun xavfsiz yordamchining 6 ta qoidasini yozing.

    5. Yordamchilar to'plami

      3 ta turli maqsad uchun tizimli promptlar to'plamini tuzing.

    6. Taqqoslash

      Bir xil vazifani tizimli prompt bilan va usiz bajarib, natijalarni tahlil qiling.
