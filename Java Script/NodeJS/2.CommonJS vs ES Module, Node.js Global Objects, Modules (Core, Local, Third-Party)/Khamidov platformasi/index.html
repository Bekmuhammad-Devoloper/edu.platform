JavaScript

  • CommonJS va ES Modules (ESM)

    1. CommonJS: Node.js'ning eski, an'anaviy moduli. require() orqali import qilinadi va module.exports orqali eksport qilinadi.
    2. ESM: JavaScript'ning yangi standarti. import va export kalit so'zlari orqali ishlaydi. Hozirda Node.js'da keng tarqalmoqda.
    3. Node.js Global Obyektlari Bu obyektlarga dasturning istalgan joyidan to'g'ridan-to'g'ri murojaat qilish mumkin.

      global: Node.js'ning asosiy global obyekti.
      process: Node.js dasturi (jarayoni) haqida ma'lumot beradi.
      console: Konsolga ma'lumot chiqarish uchun.
      __dirname & __filename: Joriy fayl va uning katalogi yo'lini ko'rsatadi (CommonJS'da).

  • Core, Local, Third-Party

    1. Core (Asosiy) Modullar: Node.js bilan birga keladigan tayyor modullar. Masalan, http va fs (fayl tizimi).
    2. Local (Mahalliy) Modullar: O'zingiz yaratgan va loyihangizda ishlatadigan modullar.
    3. Third-Party (Uchinchi tomon) Modullar: Boshqa dasturchilar tomonidan yozilgan va npm orqali o'rnatiladigan modullar. Masalan, express.

  • Uyga Vazifa

    1. Restoran Mini-Tizimi: events Modulidan Foydalanish

      Ushbu topshiriqda sizdan Node.js’ning events o‘rnatilgan modulidan foydalangan holda restoran uchun sodda tizimni yaratish talab qilinadi. Asosiy maqsad – tizimning turli qismlari (oshiyona, buxgalteriya, omborxona) o‘zaro bevosita bog‘lanmasdan, hodisalar (events) orqali aloqa o‘rnatishini ko‘rsatib berish.

      Tizim Shartlari:

      • EventEmitter Ob'ekti:

        Restoran nomli asosiy ob'ekt (yoki klass) yaratish lozim. Bu ob'ekt events.EventEmitter klassidan vorislik olishi kerak. Bu unga hodisalarni e'lon qilish va tinglash imkonini beradi.

      • Yagona Hodisa (Event):

        Tizimda faqat bitta hodisa bo‘lsin. Bu hodisa nomi "buyurtma-berildi" deb nomlansin. Bu hodisa har safar mijoz buyurtma berganida ishga tushishi kerak.

      • Hodisa Tinglovchilari (Event Listeners):

        "buyurtma-berildi" hodisasini tinglovchi uchta alohida funksiya (yoki komponent) bo‘lishi shart:

        1. Oshxona: Bu funksiya buyurtma ma’lumotini qabul qilib, uni tayyorlash jarayonini simulyatsiya qilsin (masalan, konsolga "Buyurtma tayyorlanmoqda..." deb chiqarsin).
        2. Buxgalteriya: Bu funksiya buyurtma narxini olib, girgittonlarning ish haqini hisoblasin. Har bir buyurtmadan 10% miqdorida ish haqi hisoblab, umumiy summani yangilab borsin.
        3. Omborxona: Bu funksiya buyurtma tarkibiga qarab mahsulotlar (masalan, pomidor, bodring, go‘sht) miqdorini kamaytirsin. Agar buyurtmada go‘sht bo‘lsa, ombordan go‘sht miqdorini 1 ga kamaytirsingiz mumkin. Boshlang‘ich mahsulotlar zaxirasini (masalan, pomidor: 50, bodring: 40) alohida o‘zgaruvchida saqlab turing.

      • Natijani Konsolga Chiqarish:

        Barcha funksiyalar o‘z vazifalarini bajarganda, bu haqda konsolga aniq xabarlar chiqarsin. Masalan:

        • Restoran: Yangi buyurtma qabul qilindi.
        • Oshxona: Buyurtma tayyorlanmoqda...
        • Buxgalteriya: Ish haqi hisoblandi...
        • Omborxona: Pomidor miqdori kamaytirildi. Qolgan: XX

      Ushbu vazifani bajarganingizda, asosiy restoran ob'ekti o'zining "buyurtma-berildi" hodisasini e'lon qiladi va tizimning qolgan qismlari o'ziga tegishli vazifalarni mustaqil ravishda bajaradi. Bu esa kodlarning o‘zaro bog‘liqligini kamaytirib, ularni yanada modul formatiga keltiradi.

    2. ES Modules: Person (Shaxs) Ma’lumotlarini Boshqarish

      Ushbu topshiriqda sizdan JavaScript ES Modules (import/export) yordamida bir nechta alohida funksiyalarni yaratib, ularni bitta asosiy faylda birlashtirish talab qilinadi. Tizim shaxs ma'lumotlarini ko'rsatishdan oldin ma'lum bir vaqt kutib turishi kerak.

      1. Loyiha Tuzilishi

      Loyiha quyidagi alohida fayllardan iborat bo‘ladi:

      • sleep.mjs
      • random.mjs
      • person.mjs
      • main.mjs
      2. Modullar Uchun Shartlar

      1. sleep.mjs (Uxlash moduli)

        Bu modulda sleep() nomli asinxron funksiya yozing. Bu funksiya milisaniyalarda qiymat qabul qilib, o‘sha vaqt davomida kodning bajarilishini to‘xtatib tursin. Funksiya quyidagicha tuzilgan bo‘lishi kerak:

        export async function sleep(ms) { ... }

      2. random.mjs (Tasodifiy son moduli)

        Bu modulda random() nomli funksiya yarating. Funksiya 100 dan 999 gacha bo‘lgan tasodifiy butun sonni qaytarsin.

        export function random() { ... }

      3. person.mjs (Person klassi moduli)

        Bu modulda Person nomli klass yarating. Klass quyidagi xususiyatlarga ega bo‘lsin:

        • Constructor: fullName va birthYear (tug‘ilgan yil) qiymatlarini qabul qilsin.
        • getInfo() methodi: Bu metod shaxsning ma’lumotlarini, ya'ni to'liq ismini va hozirgi yoshini hisoblab matn ko'rinishida qaytarsin.
        • Getter: Klass ichida shaxsning yoshini hisoblab beruvchi getter funksiyasi yozing. getInfo() metodi aynan shu getterdan foydalansin.
        • Klassni eksport qiling.

      4. main.mjs (Asosiy fayl)

        Bu fayl barcha modullarni birlashtirib, quyidagi amallarni bajarsin:

        • sleep.mjs, random.mjs va person.mjs modullarini import qiling.
        • random() funksiyasi orqali 100 dan 999 gacha bo‘lgan tasodifiy sonni oling.
        • sleep() funksiyasini chaqirib, unga tasodifiy sonni milisaniyada bloklab turish uchun kiriting.
        • sleep() funksiyasi tugagach, Person klassining yangi instansiyasini yarating (masalan, o'z ism-familiyangiz va tug‘ilgan yilingiz bilan).
        • getInfo() metodi orqali olingan shaxs ma'lumotini konsolga chiqaring.

      Bu topshiriq sizga modullardan samarali foydalanish, asinxron funksiyalar va klasslar bilan ishlash bo‘yicha amaliy ko‘nikmalarni beradi. Loyihani to‘g‘ri tuzish uchun package.json faylida "type": "module" ni kiritishni unutmang.
