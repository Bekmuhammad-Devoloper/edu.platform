      📋 CRUD OPERATSIYALAR TUSHUNTIRISHI

      👤 1. USER MODULI - CRUD

      Vazifasi: Foydalanuvchilar bilan bog'liq barcha CRUD operatsiyalari

      • CREATE: Yangi foydalanuvchi ro'yxatdan o'tkazish
      • READ: Foydalanuvchilarni ko'rish
      • UPDATE: Profil yangilash
      • DELETE: Foydalanuvchini o'chirish

      📦 2. CATEGORY MODULI - CRUD

      Vazifasi: Kategoriyalar bilan bog'liq CRUD operatsiyalari

      • CREATE: Yangi kategoriya yaratish
      • READ: Kategoriyalarni ko'rish
      • UPDATE: Kategoriya yangilash
      • DELETE: Kategoriya o'chirish

      🥭 3. PRODUCT MODULI - CRUD

      Vazifasi: Mahsulotlar bilan bog'liq CRUD operatsiyalari

      • CREATE: Yangi mahsulot qo'shish
      • READ: Mahsulotlarni ko'rish
      • UPDATE: Mahsulot va stok yangilash
      • DELETE: Mahsulot o'chirish

      🛒 4. ORDER MODULI - CRUD ✅ YANGI

      Vazifasi: Buyurtmalar bilan bog'liq CRUD operatsiyalari

      • CREATE: Yangi buyurtma yaratish
      • READ: Buyurtmalarni ko'rish
      • UPDATE: Buyurtma holati yangilash
      • DELETE: Buyurtma bekor qilish

      🔧 CRUD OPERATSIYALARI BATAFSIL

      👤 USER MODULI

      • CREATE: createUser(name, email, password)
      • READ: getAllUsers(), getUserById(id)
      • UPDATE: updateUser(id, data)
      • DELETE: deleteUser(id)
      • Qo'shimcha: loginUser(email, password)

      📦 CATEGORY MODULI

      • CREATE: createCategory(name, description)
      • READ: getAllCategories(), getCategoryById(id)
      • UPDATE: updateCategory(id, name, description)
      • DELETE: deleteCategory(id)

      🥭 PRODUCT MODULI

      • CREATE: createProduct(name, price, categoryId, stock)
      • READ: getAllProducts(), getProductById(id)
      • UPDATE: updateProduct(id, data), updateStock(id, stock)
      • DELETE: deleteProduct(id)
      • Qo'shimcha: getProductsByCategory(categoryId)

      🛒 ORDER MODULI

      • CREATE: createOrder(userId, productId, quantity)
      • READ: getAllOrders(), getOrderById(id)
      • UPDATE: updateOrderStatus(id, status)
      • DELETE: cancelOrder(id), deleteOrder(id)
      • Qo'shimcha: getOrdersByUser(userId)

      🌐 API ENDPOINTS - CRUD

      👤 USER APIs:

      POST /api/users # CREATE - Yangi user
      GET /api/users # READ - Barcha users
      GET /api/users/:id # READ - Bitta user
      PUT /api/users/:id # UPDATE - User yangilash
      DELETE /api/users/:id # DELETE - User o'chirish
      POST /api/users/login # Qo'shimcha - Login

      📦 CATEGORY APIs:

      POST /api/categories # CREATE - Yangi kategoriya
      GET /api/categories # READ - Barcha kategoriyalar
      GET /api/categories/:id # READ - Bitta kategoriya
      PUT /api/categories/:id # UPDATE - Kategoriya yangilash
      DELETE /api/categories/:id # DELETE - Kategoriya o'chirish

      🥭 PRODUCT APIs:

      POST /api/products # CREATE - Yangi mahsulot
      GET /api/products # READ - Barcha mahsulotlar
      GET /api/products/:id # READ - Bitta mahsulot
      PUT /api/products/:id # UPDATE - Mahsulot yangilash
      DELETE /api/products/:id # DELETE - Mahsulot o'chirish
      GET /api/categories/:categoryId/products # READ - Kategoriya mahsulotlari

      🛒 ORDER APIs:

      POST /api/orders # CREATE - Yangi buyurtma
      GET /api/orders # READ - Barcha buyurtmalar
      GET /api/orders/:id # READ - Bitta buyurtma
      PUT /api/orders/:id # UPDATE - Buyurtma yangilash
      DELETE /api/orders/:id # DELETE - Buyurtma bekor qilish
      GET /api/users/:userId/orders # READ - User buyurtmalari

      🎯 LOYIHA MUVAFFAQIYATI MEZONLARI

      Loyiha muvaffaqiyatli yakunlanganligi uchun quyidagilar bajarilishi kerak:

      • CREATE: Har bir modulda yangi ma'lumot qo'shish to'g'ri ishlaydi
      • READ: Barcha va individual ma'lumotlarni o'qish to'g'ri ishlaydi
      • UPDATE: Mavjud ma'lumotlarni yangilash to'g'ri ishlaydi
      • DELETE: Ma'lumotlarni xavfsiz o'chirish to'g'ri ishlaydi
      • JSON: Barcha ma'lumotlar JSON fayllarda to'g'ri saqlanadi
      • API: Barcha CRUD endpoint'lar to'g'ri ishlaydi va javob beradi

      🚀 Bu tarzda har bir modul uchun to'liq CRUD operatsiyalari sizning mavjud strukturangiz asosida amalga oshiriladi.
