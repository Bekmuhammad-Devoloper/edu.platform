  • Nodejs

    Nima bu Node.js? JavaScript odatda brauzerda ishlaydigan til deb bilamiz. U foydalanuvchi interfeysini interaktiv qilish uchun ishlatiladi. Lekin, Node.js JavaScript-ni brauzerdan tashqarida, ya'ni serverda yoki kompyuterning o'zida ishlashiga imkon beruvchi bir runtime environment (ishlash muhiti) hisoblanadi.
    Node.js Google tomonidan ishlab chiqilgan V8 JavaScript engine ustiga qurilgan. V8 juda tez va samarali. Node.js esa bu V8 dvigateliga fayl tizimi, tarmoq ulanishlari va boshqa server vazifalarini bajarish imkoniyatini beradi.
    Node.js Nimaga Kerak? Server yaratish: Eng muhim vazifasi bu server tomonida dasturlar yozish. Masalan, veb-ilovalarning API (ma'lumotlar bazasi bilan aloqa qiluvchi qismi) qismini Node.js da yaratish mumkin.
    CLI (Command Line Interface) dasturlari: Komanda satrida ishlaydigan dasturlar yaratish uchun ham qulay. Masalan, "create-react-app" kabi vositalar Node.js da yozilgan.
    Real-time ilovalar: Chat dasturlari, onlayn o'yinlar kabi tezkor aloqa talab qiladigan ilovalar uchun ideal.

  • Nodejs install

    Node.js va NPM ni Yuklab Olish:
    Node.js ning rasmiy veb-saytiga (https://nodejs.org/) kiring.
    Siz ikkita versiyani ko'rasiz: LTS (Long Term Support) va Current. Yangi boshlovchilar uchun LTS versiyasini o'rnatish tavsiya etiladi, chunki u barqaror va sinovdan o'tgan.
    Yuklab olingan .exe (Windows), .pkg (macOS) yoki .tar.xz (Linux) faylini ishga tushirib, o'rnatish jarayonini yakunlang. O'rnatish jarayonida hech qanday maxsus sozlamani o'zgartirish shart emas.
    O'rnatilganini Tekshirish:
    Terminal yoki Command Prompt (CMD) ni oching.
    Quyidagi buyruqlarni kiriting:
    node -v
    npm -v
    Agar versiya raqamlari ko'rinsa (masalan, v18.17.0 va 9.6.7), demak Node.js va NPM muvaffaqiyatli o'rnatilgan.

  • NPM (Node Package Manager)

    NPM Node.js bilan birga keladigan paket menejeri hisoblanadi. Paket (yoki modul) boshqa dasturchilar tomonidan yozilgan va sizning loyihangizda qayta ishlatiladigan kodlar to'plami. NPM butun dunyo bo'ylab dasturchilar tomonidan yaratilgan juda katta miqdordagi paketlarni o'z ichiga olgan markaziy baza hisoblanadi.
    NPM ning asosiy vazifalari: Paketlarni yuklab olish: Boshqa birovning kodini loyihangizga qo'shish.
    Paketlarni yangilash: Loyihangizdagi paketlarning yangi versiyalarini o'rnatish.
    Loyihani boshqarish: package.json fayli yordamida loyiha sozlamalarini boshqarish.

  • NPX (Node Package Execute)

    NPX bu NPM 5.2 versiyasidan boshlab Node.js bilan birga keladigan yana bir vosita. NPX ning asosiy maqsadi — o'rnatilmagan paketlarni to'g'ridan-to'g'ri ishga tushirish.
    NPX va NPM o'rtasidagi farq: NPM paketlarni o'rnatadi (install). O'rnatilgan paket node_modules papkasiga va package.json ga yoziladi.
    NPX paketlarni ishga tushiradi (execute) va ish tugagach ularni o'chirib tashlaydi.

  • Uyga vazifa

    Masala: Shaxsiy NPM paketi yaratish va uni e'lon qilish

    Ushbu masala sizdan Node.js va NPM bo'yicha olgan bilimlaringizni amalda qo'llashni talab qiladi. Siz o'z ism-familiyangiz bilan nomlangan o'zingizning shaxsiy NPM paketingizni yaratishingiz va uni hamma uchun ochiq (public) qilish uchun NPM registriga yuklashingiz kerak bo'ladi.

    Asosiy Shartlar

    Yaratiladigan paket:

    • O'z ism va familiyangiz asosida noyob nomga ega bo'lishi kerak.
    • getInfo nomli bitta funksiyani eksport qilishi kerak.
    • Bu funksiya chaqirilganda, konsolga bugungi darsdagi asosiy tushunchalar haqida qisqacha ma'lumot (mini-konspekt) chiqarishi lozim.

    Vazifani Bajarish uchun Qadamlar

    Quyidagi qadamlarni bosqichma-bosqich bajarish orqali masalani hal qiling:

    1. Loyihani o'rnatish:

      Yangi papka yarating va terminalda ushbu papkaga kiring. Loyiha uchun package.json faylini yaratish maqsadida npm init -y buyrug'ini bajaring. Bu loyiha haqidagi asosiy ma'lumotlarni saqlash uchun zarur.

    2. Paket nomini tanlash:

      Yaratilgan package.json faylini oching va "name" maydonini o'zgartiring. NPM'dagi boshqa paketlar bilan nomlarning to'qnashmasligi uchun ism va familiyangizni kichik harflarda, defis orqali ajratib yozish tavsiya etiladi. Misol uchun: "ali-valiyev".

    3. Paket kodini yozish:

      Loyihaning asosiy fayli bo'lgan index.js (yoki package.json da belgilangan boshqa fayl) ni yarating. Bu faylda getInfo funksiyasini yozing. Funksiya ichida siz bugun o'rgangan Node.js, NPM, va boshqa tushunchalar haqida console.log() orqali ma'lumot chiqaring. Funksiyani boshqa loyihalarda foydalanish mumkin bo'lishi uchun module.exports orqali eksport qilishni unutmang.

    4. NPM'ga kirish:

      Paketni publish qilishdan oldin, siz NPM hisobingizga kirishingiz kerak. Terminalda npm login buyrug'ini bajaring va so'ralgan ma'lumotlarni (foydalanuvchi nomi, parol, elektron pochta) kiriting.

    5. Paketni e'lon qilish:

      Barcha tayyorgarliklar yakunlangach, terminalda npm publish buyrug'ini bajaring. Bu buyruq sizning paketingizni NPM registriga yuklaydi va u hamma uchun ochiq bo'ladi.

    6. Natijani bo'lishish:

      Paket muvaffaqiyatli e'lon qilingandan so'ng, sizga paket nomi va unga tegishli NPM havola ko'rsatiladi. Bu ma'lumotlarni (paket nomi va havola) ustozingizga yuboring.
