  • Os (Operating System)

    os (Operating System) moduli Node.js'da operatsion tizim (OS) bilan ishlash uchun ishlatiladi. Bu modul, OS haqida ma'lumot olish, tizim resurslariga kirish va ba'zi operatsiyalarni bajarish imkonini beradi.

    Koʻp ishlatiladigan metodlar

    1. os.homedir():
      Foydalanuvchining asosiy (home) katalogi yoʻlini qaytaradi.
      Foydalanish: const homeDir = os.homedir();
      Natija (misol): /home/user yoki C:\Users\user
    2. os.hostname():
      Kompyuterning tarmoq nomini (hostname) qaytaradi.
      Foydalanish: const hostname = os.hostname();
      Natija (misol): My-PC
    3. os.platform():
      Operatsion tizim turini qaytaradi (masalan, 'win32', 'linux', 'darwin').
      Foydalanish: const platform = os.platform();
      Natija (misol): linux
    4. os.arch():
      Operatsion tizimning arxitekturasini (masalan, 'x64', 'arm') qaytaradi.
      Foydalanish: const arch = os.arch();
      Natija (misol): x64
    5. os.cpus():
      CPU yadrolari haqida maʼlumotni massiv shaklida qaytaradi.
      Foydalanish: const cpus = os.cpus();
      Natija (misol): 
      [
  { model: 'Intel(R) Core(TM) i5-8250U CPU @ 1.60GHz', speed: 1800, ... },
  { model: 'Intel(R) Core(TM) i5-8250U CPU @ 1.60GHz', speed: 1800, ... }
]
    6. os.freemem():
      Tizimda mavjud boʻsh RAM miqdorini baytlarda qaytaradi.
      Foydalanish: const freeMem = os.freemem();
      Natija (misol): 8429383680
    7. os.totalmem():
      Tizimdagi umumiy RAM miqdorini baytlarda qaytaradi.
      Foydalanish: const totalMem = os.totalmem();
      Natija (misol): 17179869184

    Kam ishlatiladigan metodlar

    1. os.endianness():
      CPU'ning bayt tartibini (endianness) qaytaradi ('BE' yoki 'LE').
      Foydalanish: const endianness = os.endianness();
      Natija (misol): LE
    2. os.getPriority() / os.setPriority():
      Jarayonning ustuvorligini (priority) olish va oʻrnatish.
      Foydalanish: const priority = os.getPriority();
      Natija (misol): 0
    3. os.userInfo():
      Foydalanuvchi haqida maʼlumotlarni qaytaradi.
      Foydalanish: const userInfo = os.userInfo();
      Natija (misol): 
      {
  uid: 1000,
  gid: 1000,
  username: 'testuser',
  homedir: '/home/testuser',
  shell: '/bin/bash'
}

  • fs (File System)

    fs (File System) moduli Node.js'da fayllar va kataloglar bilan ishlash uchun asosiy modul hisoblanadi. Unda asosan ikkita metodlar toifasi mavjud: asinxron (async) va sinxron (sync) metodlar. Asinxron metodlar ko'proq ishlatiladi, chunki ular dasturning asosiy ish zanjirini (main thread) bloklamaydi.

  • path Moduli

    path moduli fayl tizimi yo'llari bilan ishlash uchun mo'ljallangan. Uning yordamida har xil operatsion tizimlar uchun to'g'ri yo'l yaratish mumkin. Bu veb-server va boshqa loyihalarni turli OS'larda ishlashini ta'minlash uchun juda muhim.

    Eng Ko'p Foydalaniladigan Metodlar:

    1. path.join([...paths]):
      Berilgan yoʻl qismlarini birlashtirib, operatsion tizimga mos yoʻl yaratadi. Bu fayl yoʻllari bilan ishlashda eng muhim va universal usullardan biridir.
      Foydalanish: const filePath = path.join('/users', 'john', 'docs', 'report.txt');
      Natija (misol): /users/john/docs/report.txt
    2. path.resolve([...paths]):
      Berilgan yoʻl qismlarini absolyut (mutlaq) yoʻlga aylantiradi. Agar yoʻl oldidan ildiz (root) katalog belgisi boʻlmasa, joriy ish katalogi (current working directory) asos qilib olinadi.
      Foydalanish: const absolutePath = path.resolve('users', 'john', 'docs');
      Natija (misol): /home/project/users/john/docs
    3. path.extname(path):
      Berilgan yoʻldagi fayl nomining kengaytmasini (extension) qaytaradi.
      Foydalanish: const ext = path.extname('document.pdf');
      Natija (misol): .pdf
    4. path.basename(path, [ext]):
      Yoʻlning oxirgi qismini (fayl yoki katalog nomini) qaytaradi. Ikkinchi parametr sifatida kengaytmani berib, uni natijadan chiqarib tashlash mumkin.
      Foydalanish: const baseName = path.basename('/users/john/photos/image.jpg');
      Natija (misol): image.jpg
    5. path.dirname(path):
      Berilgan yoʻlning katalog qismini (fayl joylashgan papka yoʻlini) qaytaradi.
      Foydalanish: const dirName = path.dirname('/users/john/photos/image.jpg');
      Natija (misol): /users/john/photos
    6. path.parse(path):
      Berilgan yoʻlni tarkibiy qismlarga (root, dir, base, ext, name) ajratib, ob'ekt koʻrinishida qaytaradi.
      Foydalanish: const parsedPath = path.parse('/home/user/data/file.txt');
      Natija (misol): 
      {
  root: '/',
  dir: '/home/user/data',
  base: 'file.txt',
  ext: '.txt',
  name: 'file'
}

    Kam ishlatiladigan metodlar

    1. path.posix va path.win32:
      Bu ob'ektlar maxsus platformalar (POSIX - Linux/macOS, win32 - Windows) uchun yoʻl bilan ishlashga xos metodlarni oʻz ichiga oladi. Odatda, path moduli oʻzi avtomatik tarzda toʻgʻri platformani aniqlaganligi sababli kamdan-kam ishlatiladi.
      Foydalanish: const winPath = path.win32.join('C:\', 'Users', 'John');
      Natija (misol): C:\Users\John
    2. path.isAbsolute(path):
      Berilgan yoʻlning absolyut (mutlaq) yoʻl ekanligini tekshiradi va true yoki false qiymat qaytaradi.
      Foydalanish: const isAbs = path.isAbsolute('/home/user/file.txt');
      Natija (misol): true

  • url Moduli

    url moduli veb-server dasturlashda URL manzillarini tahlil qilish, formatlash va birlashtirish uchun ishlatiladi. Bu modul URLni turli qismlarga bo'lish va ular bilan ishlashda katta yordam beradi.

    Koʻp ishlatiladigan metodlar va sinf

    1. url.parse(url, [query_string]):
      URLni tarkibiy qismlarga ajratib, ob'ekt ko'rinishida tahlil qiladi.
      Foydalanish: const parsedUrl = url.parse('https://www.example.com/path?id=123');
      Natija (misol): 
      {
  protocol: 'https:',
  hostname: 'www.example.com',
  pathname: '/path',
  query: 'id=123',
  ...
}
    2. url.format(urlObject):
      Ob'ekt ko'rinishidagi URL qismlarini birlashtirib, to'liq string formatidagi URLga qaytaradi.
      Foydalanish: const formattedUrl = url.format({ protocol: 'https:', hostname: 'www.example.com' });
      Natija (misol): https://www.example.com/
    3. URL sinfi (constructor):
      Yangi URL ob'ektini yaratish va uning qismlariga osonroq, zamonaviy usulda kirish uchun ishlatiladi. url.parse() metodiga nisbatan tavsiya etiladi.
      Foydalanish: const myUrl = new URL('https://www.example.com/path?id=123');
      Natija (misol): 
      {
  href: 'https://www.example.com/path?id=123',
  protocol: 'https:',
  hostname: 'www.example.com',
  searchParams: URLSearchParams { 'id' => '123' },
  ...
}

    Kam ishlatiladigan metodlar

    1. url.resolve():
      Ikki URL qismini birlashtirib, yangi URL yaratadi. Ko'pincha URL sinfi va uning konstruktori bu vazifani samaraliroq bajaradi.
      Foydalanish: const resolvedUrl = url.resolve('http://example.com/a/', 'b');
      Natija (misol): http://example.com/a/b
    2. url.searchParams:
      URL sinfining bir qismi bo'lib, so'rov satri (query string) bilan ishlashga mo'ljallangan. URLSearchParams interfeysi orqali kalit va qiymatlarni osonlik bilan boshqarish imkonini beradi.
      Foydalanish: 
      const myUrl = new URL('http://example.com/?name=john');
  myUrl.searchParams.get('name'); // 'john'

      Natija (misol): john

  • Uyga vazifa

    1. Papkalar Yaratish Funksiyasi (createFolders())

      Maqsad: Bu funksiyaning asosiy maqsadi — berilgan bir yoki bir nechta nom boʻyicha yangi papkalarni yaratish.
      Qoidalar: Funksiya kamida 1 ta, koʻpi bilan 100 ta parametr (papka nomi) qabul qilishi kerak.
      Yechimga yondashuv:
      Funksiya yaratiladi va u ...folderNames yordamida cheksiz miqdordagi argumentlarni massivga yigʻib oladi. Birinchi boʻlib, parametrlar soni (folderNames.length) 1 dan kam yoki 100 dan koʻp boʻlsa, xatolik haqida xabar beriladi. Soʻngra, har bir papka nomi uchun fs.mkdir() yoki fs.mkdirSync() funksiyasidan foydalanib papka yaratiladi. Har bir papka yaratilganda yoki allaqachon mavjud boʻlganda konsolga tegishli xabar chiqariladi.
    2. cars.json Faylini Yaratish

      Maqsad: Maʼlumotlarni (mashinalar roʻyxatini) saqlash uchun alohida JSON formatidagi fayl yaratish.
      Yechimga yondashuv:
      Dastlab, fs.existsSync() yordamida cars.json fayli mavjud yoki yoʻqligi tekshiriladi. Agar fayl mavjud boʻlmasa, fs.writeFileSync() funksiyasi yordamida boʻsh massiv [] bilan yangi fayl yaratiladi. Bu keyinchalik maʼlumot qoʻshishda xatoliklarning oldini oladi.
    3. Faylga Maʼlumot Yozish Funksiyasi

      Maqsad: Yangi avtomobil maʼlumotini (masalan, {id: 1, model: "audi", price: 1000}) cars.json fayliga qoʻshish.
      Yechimga yondashuv:
      Bu yerda eng muhim qadam — faylni oʻqimasdan turib toʻgʻridan-toʻgʻri yozmaslik. Aks holda, oldingi maʼlumotlar oʻchib ketadi. fs.readFile() yordamida fayldagi barcha maʼlumotlar oʻqib olinadi. Olingan maʼlumotlar JSON.parse() bilan JavaScript obyekti yoki massiviga aylantiriladi. Yangi maʼlumot (obyekt) bu massivga .push() metodi bilan qoʻshiladi. Oʻzgartirilgan massiv JSON.stringify() yordamida yana JSON formatiga oʻtkaziladi va fs.writeFile() bilan faylga qayta yoziladi.
    4. Barcha Maʼlumotni Olib Berish Funksiyasi

      Maqsad: cars.json faylida saqlangan barcha avtomobillar roʻyxatini olish.
      Yechimga yondashuv:
      Bu vazifa uchun fs.readFile() funksiyasidan foydalaniladi. Fayldagi maʼlumotlar oʻqib olinadi. Oʻqilgan maʼlumotlar matn koʻrinishida boʻlganligi uchun, ularni JavaScript obyekti (massiv)ga aylantirish uchun JSON.parse() dan foydalaniladi. Natija chaqiruvchi funksiyaga qaytariladi yoki bevosita konsolga chiqariladi. Asinxron funksiya boʻlgani uchun Promise yoki async/await ishlatish maqsadga muvofiq.
    5. Maʼlumotni ID Orqali Oʻchirish Funksiyasi

      Maqsad: Berilgan id ga ega boʻlgan avtomobil maʼlumotini cars.json faylidan butunlay oʻchirib tashlash.
      Yechimga yondashuv:
      Avvalgi vazifadagi kabi, faylning barcha maʼlumotlari fs.readFile() orqali oʻqib olinadi. Olingan maʼlumot massivga aylantiriladi. Massivdagi elementlarni filtratsiya qilish uchun .filter() metodi ishlatiladi. Bu metod, berilgan id ga teng boʻlmagan barcha elementlarni yangi massivga jamlaydi. Yangilangan (keraksiz maʼlumot oʻchirilgan) massiv yana JSON.stringify() bilan JSON formatiga oʻtkaziladi. Oxirida fs.writeFile() yordamida yangi massiv faylga qayta yoziladi va bu bilan keraksiz maʼlumot oʻchirilgan boʻladi. Agar berilgan id topilmasa, bu haqida konsolga xabar chiqarish mumkin.
