  • This, Object ichida Function(Method)

    This object hisoblanib object ichidagi functionda this ishlatilsa aynan shu objectga murojat qilishga yordam beradi. Object ichida constructor function va declaration function expression functiondan foydalanish tavsiya qilinadi, Arrow functiondan foydalanilsa ham boladi ammo arrow funtiondi ichida thisdan foydalanilsa Global Objectga murojat qiladi osha objectga emas.

  • IIFE

    Immediately Invoked Function Expression (IIFE) bu functiondan js da darhol chaqirish kerak bolganda foydalanamiz.IIFE yordamida maxfiy ma'lumotlarni tashqi koddan himoya qilish mumkin. Faqat IIFE qaytaradigan natijalarga tashqaridan kirish mumkin.

  • Call-back function (call apply bind)

    JavaScript’da har bir funksiya obyekt hisoblanadi va call, apply, bind metodlari funksiyalarning qanday chaqirilishini va this qiymati nima bo‘lishini nazorat qiladi: this konteksti: Funksiya ichida this qaysi ob’ektga ishora qilishini belgilaydi. Argumentlar: Funksiyaga qanday ma’lumotlar uzatilishini boshqaradi. Bu metodlar callback funksiyalar bilan ishlaganda yoki ma’lumotlar bazasi operatsiyalarida (masalan, MongoDB so‘rovlari) kontekstni to‘g‘ri sozlash uchun ishlatiladi.

    call va aply bir hill ishlaydi.Ularni farqi functionga paramatr berishda aply array sifatida parametr qabul qiladi.Bind faqat object methodi shu deb korsatib qoyadi lekin call qilmaydi ozimiz ishlatganimizda call qilishimiz kerak.
