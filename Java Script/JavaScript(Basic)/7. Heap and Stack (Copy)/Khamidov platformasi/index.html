  • JS internals (Heap and stack)

    Heap – dinamik xotira maydoni bo‘lib, unda murakkab va o‘lchami oldindan noma'lum bo‘lgan ma'lumotlar saqlanadi.

    Primitiv bo‘lmagan ma'lumotlar heapda saqlanadi, lekin ularga ishora qiluvchi referenslar stackda joylashadi.

    Heapda xotira boshqaruvi Garbage Collector tomonidan avtomatik ravishda tozalanadi, ya'ni ishlatilmayotgan ob'ektlar xotiradan olib tashlanadi.

    ------------------------------------------------------------------------------------------------------------------

    Stack – bu LIFO (Last In, First Out) tuzilmasiga ega xotira maydoni. Ya'ni, oxirgi qo‘shilgan ma'lumot birinchi olinadi. JavaScript'da stack odatda funksiyalar chaqiruvi (call stack) va o‘zgaruvchilar uchun ishlatiladi.

    Stackda statik xotira ajratiladi, ya'ni o‘zgaruvchilar va ularning qiymatlari oldindan belgilangan hajmda saqlanadi.

    Oddiy (primitiv) ma'lumot turlari (masalan, number, string, boolean, null, undefined) stackda saqlanadi.

    Funksiyalar chaqirilganda ularning konteksti (local variables, arguments) stackga joylashadi va funksiya tugagach, stackdan o‘chiriladi.

  • Shallow copy and Deep copy

    Shallow(Yuzaki nusxa) copy obyektdagi faqat yuqori darajadagi qiymatlarni nusxalaydi. Bu shuni anglatadiki, agar obyekt ichida boshqa obyekt yoki massiv bo'lsa, ular faqat havola (reference) orqali nusxalanadi, lekin haqiqiy qiymatlar nusxalanmaydi.

    Deep(Chuqur nusxa) copy obyektdagi barcha qiymatlarni, shu jumladan ichki obyektlar yoki massivlarni ham nusxalaydi. Bunda har bir element uchun alohida xotira ajratiladi, shuning uchun original va nusxa bir-biridan mustaqil bo'ladi.

  • Amaliyot (Copy)

    Shallow copy

    1. Massivni shallow copy qilish:

      // Berilgan massivni shallow copy qiling.

      const arr = [1, 2, 3, 4];

    2. Obyektni Object.assign() yordamida shallow copy qilish:

      // Berilgan obyektni `Object.assign()` yordamida nusxa oling.

      const obj = { a: 1, b: 2, c: 3 };

    3. Shallow copy spread operator bilan:

      // Obyektdan nusxa oling va uni konsolda tekshiring.

      const person = { name: "Ali", age: 25 };

    4. Shallow copy va chuqur obyekt:

      // Quyidagi obyektni shallow copy qiling va `address`ni o'zgartiring.

      const user = { name: "Bek", address: { city: "Toshkent" } };

      Shellow copy oling!(copiedUser)

      copiedUser.address.city = "Samarqand";

      console.log(user.address.city); // Nima chiqadi?

    5. Mahsulotlar ro‘yxatini nusxalash: E-tijorat saytida mahsulotlar ro‘yxatini shallow copy qilib, keyin nusxa bilan ishlash kerak.

      const products = [

      { id: 1, name: "Telefon", price: 500 },

      { id: 2, name: "Laptop", price: 1000 },

      ];

      Shellow copy oling!(copiedProducts)

      copiedProducts[0].price = 600;

      console.log(products[0].price); // Nima chiqadi?

    Deep copy

    1. Kompleks obyektni nusxalash: Agar obyekt ichida boshqa obyektlar yoki massivlar bo‘lsa, deep copy qilish zarur bo‘ladi, chunki shallow copy faqat yuqori darajadagi qiymatlarni nusxalaydi.

      const student = {

      name: "Bek",

      subjects: ["Math", "Physics", "Chemistry"],

      address: { city: "Toshkent", country: "Uzbekistan" },

      };

      // Deep copy qilish

    2. Mahsulotlar ro‘yxatidagi obyektlarni chuqur nusxalash: Onlayn do‘konda mahsulotlar ro‘yxatini chuqur nusxalab, mahsulotning narxini yangilash.

      const products = [

      { name: "Laptop", price: 1000, specs: { processor: "Intel i7", ram: "16GB" } },

      { name: "Phone", price: 500, specs: { processor: "Snapdragon", ram: "8GB" } }

      ];

      // Deep copy qilish

    3. Foydalanuvchi ma'lumotlarini chuqur nusxalash: Foydalanuvchi profilini chuqur nusxalab, foydalanuvchining barcha ma'lumotlarini o‘zgartirish.

      const user = {

      id: 1,

      name: "Ali",

      preferences: {

      theme: "dark",

      language: "uzbek"

      }

      };

      // Deep copy qilish

    4. O‘quvchilarni va ularning baholarini chuqur nusxalash: Talabalar va ularning baholarini chuqur nusxalab, faqat bir o‘quvchining baholarini yangilash.

      const students = [

      { name: "Anvar", grades: { math: 90, physics: 85 } },

      { name: "Zarina", grades: { math: 95, physics: 90 } }

      ];

      // Deep copy qilish
