    Sana ustida amallar bajarish (qo‘shish, ayirish) mumkin.

  • Amaliyot(Date)

    1. Foydalanuvchi tug‘ilgan sanasini bazaga saqlash kerak. Sana `YYYY-MM-DD` formatida bo‘lishi lozim.

                                  let input = "01/06/2025";
                            //Natija: "2025-06-01"

      Format: YYYY-MM-DD

    2. Sertifikat chiqarish uchun sana `DD-MM-YYYY` ko‘rinishida yozilishi kerak.

                                let date = new Date("2025-06-01");
                         //Natija: "01-06-2025"

      Format: DD-MM-YYYY

    3. AQShda foydalanuvchidan sana so‘raladi va `MM-DD-YYYY` formatda uzatiladi.

                                let date = new Date("2025-06-01");
                          //Natija: "06-01-2025"

      Format: MM-DD-YYYY

    4. Sana fayl nomi uchun kerak: `report_YYYY/MM/DD.txt` ko‘rinishida bo‘lishi lozim.

                                let date = new Date("2025-06-01");
                          // "report_2025/06/01.txt"

      Format: YYYY/MM/DD

    5. Telegram boti foydalanuvchiga sanani `DD.MM.YYYY` formatida jo‘natadi.

                                let date = new Date("2025-06-01");
                          //Natija: "01.06.2025"

      Format: DD.MM.YYYY

    6. Frontend sahifada sana foydalanuvchining brauzer tiliga mos ravishda chiqariladi.

                                let date = new Date("2025-06-01");
                          // Masalan: "01.06.2025" yoki "6/1/2025"

      Format: toLocaleDateString()

    7. API JSON formatida sanani `ISO 8601` formatda yuboradi.

                                let date = new Date("2025-06-01T00:00:00Z");
                         //date.toISOString() "2025-06-01T00:00:00.000Z"

      Format: ISO 8601

    8. Backend JWT token muddati Unix timestamp (sekund) formatida saqlaydi.

                                 //new Date("2025-06-01") => 1743801600 s

      Format: Unix timestamp (seconds)

    9. Email yuborishda headerda `toUTCString()` formatda sana yoziladi.

                                let date = new Date("2025-06-01");
                         // "Sun, 01 Jun 2025 00:00:00 GMT"

      Format: toUTCString()

    10. Postlar sarlavhasida sana `Sun, Jun 1 2025` ko‘rinishida ko‘rsatiladi.

                                let date = new Date("2025-06-01");
                          // "Sun, Jun 1, 2025"

      Format: ddd, MMM D YYYY

      Metod: JSON.parse()

    3. Masala 3: Mahsulotlar ro‘yxati berilgan. Uni localStorage'ga saqlash uchun JSON formatiga o‘tkazing, keyin esa localStorage'dan olib, obyekt sifatida foydalaning.

       // Saqlash let products = [ { name: "Book", price: 30 }, { name: "Pen", price: 5 } ];

      Metodlar: JSON.stringify(), JSON.parse(), localStorage

  • Amaliyot(Destruction)

    1. Masala 1: Quyidagi foydalanuvchi obyektidan name va age qiymatlarini destrukturizatsiya yordamida ajrating.

      Metodlar: object destructuring

    2. Masala 2: Quyidagi funksiyaga foydalanuvchi obyektini uzatganingizda, destrukturizatsiya yordamida faqat email va phone qiymatlarini oling.

    3. Masala 3: Quyidagi massivdan destrukturizatsiya orqali birinchi va uchinchi elementni oling. Ikkinchi elementni tashlab ketilsin.

      Date()

    1. Masala 1: Foydalanuvchi tug‘ilgan sanasini bazaga saqlash kerak. Sana YYYY-MM-DD formatida bo‘lishi lozim. 

       let input = "01/06/2025"; // Natija: "2025-06-01"

      Format: YYYY-MM-DD

    2. Masala 2: Foydalanuvchidan sana qabul qilinadi (YYYY-MM-DD). Sananing yil va oy qismini ajratib oling, oy nomini inglizcha chiqarilsin.

       let input = "2023-12-25";

      Format: YYYY-MM-DD → yil va oy nomi

    3. Masala 3: Sana stringi DD.MM.YYYY formatida berilgan. Uni YYYY/MM/DD formatiga o‘zgartiring. 

       let input = "15.09.2024"; // Natija: "2024/09/15"

      Format: DD.MM.YYYY → YYYY/MM/DD

    4. Masala 4: Sana berilgan: 2025-07-20. Sanaga 10 kun qo‘shib, natijani toLocaleDateString() formatida chiqarilsin.

       let input = "2025-07-20";

      Format: YYYY-MM-DD + 10 kun → toLocaleDateString()

    5. Masala 5: Foydalanuvchi kiritgan sananing kunini (day) 1 ga kamaytiring va natijani YYYY-MM-DD formatida chiqaring.

       let input = "2024-01-01";

      Format: YYYY-MM-DD - 1 kun → YYYY-MM-DD
