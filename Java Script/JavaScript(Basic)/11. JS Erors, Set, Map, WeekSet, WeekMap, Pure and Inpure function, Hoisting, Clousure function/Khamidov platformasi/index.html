  • JS Errors

    1. Syntax Eror
      Qachon chiqadi: Kod yozilishida sintaksis (tuzilish) xato bo‘lsa.
      Sababi: Noto‘g‘ri yozilgan kod (masalan, qavs yopilmagan, vergul noto‘g‘ri qo‘yilgan).

    2. Referens Eror
      Qachon chiqadi: O‘zgaruvchi yoki funksiya ishlatilganda, u hali aniqlanmagan (ya’ni mavjud emas).
      Sababi: E'lon qilinmagan nomni chaqirish.

    3. Type Eror
      Qachon chiqadi: Noto‘g‘ri turdagi qiymat bilan noto‘g‘ri amal bajarilsa.
      Sababi: Masalan, null ustida metod chaqirish, raqam ustida toUpperCase() chaqirish.

    4. Range Eror
      Qachon chiqadi: Stack hotira tolib qolsa.
      Sababi: Qiymat ruxsat etilgan chegaradan chiqib ketsa.

  • Amaliyot(Pure and Inpure function)

    Pure Function (Toza funksiya)

    Kiruvchi qiymatlarga (argumentlarga) bog‘liq bo‘ladi
    Hech qanday tashqi holatga (global o‘zgaruvchi, I/O, DOM, Math.random, Date va h.k.) bog‘lanmaydi
    Har doim bir xil kiruvchidan bir xil natija qaytaradi


    Inpure Function (Iflos funksiya)

    Tashqi holatga bog‘liq bo‘ladi (masalan, global o‘zgaruvchi, I/O, DOM, random, vaqt) bog‘lanmaydi
    Bir xil argument bersak ham, natijasi har xil bo‘lishi mumkin.

      Amaliyot

    1. Foydalanuvchi mahsulot narxini kiritadi. QQS (15%) qo‘shiladi va umumiy narx qaytariladi. Bu hisoblash pure function orqali bajariladi.

                                function calculateTotal(price) {
                           
                          }
                          
                          console.log(calculateTotal(100)); // 115

      Pure function bilan (kiruvchilar asosida hisoblaydi, tashqi holatga bog‘liq emas)

    2. Foydalanuvchi buyurtma berganda unga buyurtma vaqti qaytariladi. Bu ma’lumot impure function orqali olinadi, chunki tashqi holatga (vaqtga) bog‘liq. 

                                function getOrderTime() {
                          }
                          
                          console.log(getOrderTime()); // Har safar har xil vaqt

      Impure function bilan (tashqi holat – system time ishlatiladi)

    3. Foydalanuvchi mahsulot narxi va chegirma foizini kiritadi. Biz unga chegirmali narxni qaytaramiz. Hisoblash pure function orqali amalga oshiriladi.

      Pure function bilan (kiruvchilarga bog‘liq, tashqi ta’sir yo‘q)

    4. Foydalanuvchi ro‘yxatdan o‘tganda, uni tabriklovchi xabar console.log() bilan chiqariladi. Bu impure function, chunki tashqi ta’sir bor — konsolga yozuv chiqaradi.

      Impure function bilan (tashqi ta’sir: konsolga yozuv chiqariladi)

  • Amaliyot(Hoisting)

    Hoisting

    Hoisting — bu JavaScript'ning o‘ziga xos xatti-harakati bo‘lib, o‘zgaruvchilar (variables) va funksiyalar e'lonlari avtomatik ravishda faylning yoki blokning yuqorisiga “ko‘tarilishi” deganidir.

    Ammo faqat e'lon qismi yuqoriga ko‘tariladi, qiymat berilishi emas!
    Hoisting faqat Var kalit sozi va Declaration function bilangina sodir boladi.

      Amaliyot

    1. Admin panelda kiruvchilar soni visitorCount deb nomlangan o‘zgaruvchida saqlanadi. Dasturchi uni console.log bilan chiqarishga harakat qiladi, lekin kod to‘g‘ri ishlamaydi. Sababi: hoisting

      Tushuntirish: JavaScript `var visitorCount` ni yuqoriga ko‘taradi, lekin qiymatini emas.
      Shu sababli `undefined` chiqadi. Bu hoisting sababli yuzaga keladigan muammolardan biridir.

    2. Foydalanuvchi nomini kiritishdan oldin uni konsolga chiqarishga harakat qilinmoqda. Ammo `let` bilan e’lon qilingan o‘zgaruvchi hali “Temporal Dead Zone”da bo‘lganligi sababli xatolik yuz beradi.

      Tushuntirish: `let` hoist qilinadi, ammo foydalanishdan oldin qiymat belgilanmagani uchun xatolik yuz beradi.

    3. Hisoblash funksiyasi calculateTotal function expression ko‘rinishida yozilgan. Uni chaqirishga harakat qilingan, ammo xatolik yuz beradi — sababi: hoisting faqat o‘zgaruvchini ko‘taradi, qiymatini emas.

                                calculateTotal(3, 4); 
                          
                          var calculateTotal = function (a, b) {
                            return a + b;
                          };

      Tushuntirish: `var calculateTotal` hoist qilinadi, lekin qiymati (`function`) hali belgilanmagan. Shuning uchun xatolik yuz beradi.

    4. Kodda `printMessage` funksiyasi ham, `var` bilan nomi bir xil o‘zgaruvchi ham mavjud. Bu chalkashlikka sabab bo‘ladi — hoisting natijasida funksiya ustiga o‘zgaruvchi yozib ketadi.

      Tushuntirish: Avval function hoist qilinadi, lekin keyin `var` qiymati uni ustiga yozib ketadi.

    1. Mahsulot narxini hisoblaydigan funksiya yozing. U hech qanday tashqi o‘zgaruvchiga bog‘liq emas va har doim bir xil kiruvchiga bir xil natija beradi — bu pure function.

    2. Mahsulot narxini hisoblaydigan funksiya bor, lekin tashqi global o‘zgaruvchiga bog‘liq. Bu uni impure function qiladi.
