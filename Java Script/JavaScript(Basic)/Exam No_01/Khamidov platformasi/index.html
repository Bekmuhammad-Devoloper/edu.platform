  • Problematic issue 1

    1. Masala: Foydalanuvchining daromadiga qarab soliq miqdorini hisoblang.

      Shart:

      • 1000 dan kam bo‘lsa — 5%
      • 1000–9999 — 10%
      • 10000–49999 — 20%
      • 50000 dan yuqori — 30%
      • Agar noto‘g‘ri qiymat (string, null, manfiy) kiritilsa, "Noto‘g‘ri qiymat" chiqarsin.

      Foydalaniladi: let/const, console.log(), if/else if, typeof

    2. Masala: Berilgan massiv ichidan takrorlanmas ikki kishilik juftliklar ro‘yxatini chiqaring.

      Shart:

      • ["Ali", "Vali", "Karim"] => "Ali - Vali", "Ali - Karim", "Vali - Karim"
      • "Vali - Ali" yoki "Karim - Ali" bo‘lmasligi kerak

      Foydalaniladi: for loop, function, array indexing, console.log()

    3. Masala: Foydalanuvchilarning nomi va emailini tozalang, `username` maydonini qo‘shing.

      Shart:

      • Bo‘sh yoki null qiymatdagi foydalanuvchilarni olib tashlang.
      • name — trim() va toUpperCase() bilan tozalanadi.
      • email — trim() va toLowerCase() bilan tozalanadi.
      • username — emaildan `@` oldidagi qism olinadi.

      Foydalaniladi: Array.filter(), Array.map(), String.trim(), String.toLowerCase(), split(), object

    4. Masala: Fayllar ro‘yxatini ketma-ket, har birini 1 soniyadan keyin konsolga chiqaradigan funksiya yozing.

      Shart:

      • ["file1.txt", "file2.txt"] ro‘yxati navbati bilan chiqsin
      • Har biri 1 soniyada chiqsin
      • Fayl mavjud bo‘lmasa, xatolik chiqarsin

      Foydalaniladi: Promise, async/await, setTimeout(), recursion, console.log()

    5. Masala: `count` qiymatini faqat `increment`, `decrement`, `get` funksiyalari orqali boshqariladigan qilish.

      Shart:

      • Globaldan count'ga kira bo‘lmasin
      • Faqat metodlar orqali o‘zgartirish mumkin
      • Bu closure orqali amalga oshiriladi

      Foydalaniladi: function closure, return object, let (heapda saqlanadi), console.log()

    6. Masala: Objektdagi `this` noto‘g‘ri ishlayotgan metodni `bind()` yordamida tuzating va `setTimeout` bilan 2 soniyadan keyin ishga tushiring.

      Shart:

      • Metod boshqa o‘zgaruvchiga berilganda `this` yo‘qolmasligi kerak
      • bind() yordamida to‘g‘ri kontekst biriktiring
      • setTimeout bilan 2 soniyadan keyin chaqiring

      Foydalaniladi: this, bind(), function, setTimeout()

    7. Masala: Foydalanuvchining tug‘ilgan sanasidan yoshini hisoblang va hozirgi vaqtni har 10 soniyada ko‘rsating.

      Shart:

      • dob dan yoshni aniqlang
      • Har 10 soniyada joriy vaqtni HH:MM:SS formatda ko‘rsating

      Foydalaniladi: new Date(), getFullYear(), setInterval(), toLocaleTimeString(), destructuring, console.log()

    8. Masala: `WeakSet` yordamida tizimdagi foydalanuvchilarni kuzating.
