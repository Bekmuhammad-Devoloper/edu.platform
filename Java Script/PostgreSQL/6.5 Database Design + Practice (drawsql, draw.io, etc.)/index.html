Database Design va SQL Triggers

Ma'lumotlar bazasi dizayni va triggerlarni o'rganish platformasi

Database Design nima?

Ta'rif

Database Design - bu ma'lumotlar bazasining tuzilmasini, jadvallarini, ularning o'rtasidagi bog'lanishlarni va cheklovlarini loyihalashtirish jarayoni.

Nega kerak?

  • 📊 Ma'lumotlarni tartibli saqlash
  • 🚀 Tezkor qidiruv va ishlash
  • 🔒 Ma'lumotlar xavfsizligi
  • ♻️ Takrorlanishlarni kamaytirish (Normalizatsiya)
  • 🔗 Jadvallar o'rtasida mantiqiy bog'lanishlar

Asosiy Qoidalar

  • Primary Key - har bir jadvalda bo'lishi shart
  • Foreign Key - jadvallarni bog'laydi
  • Normalizatsiya - ma'lumotlarni to'g'ri taqsimlash
  • Index - qidiruv tezligini oshiradi

SQL Triggers nima?

Ta'rif

Trigger - bu jadvalda ma'lum bir hodisa (INSERT, UPDATE, DELETE, TRUNCATE) sodir bo'lganda avtomatik ishga tushadigan maxsus funksiya.

Trigger turlari

  • 🔵 INSERT Trigger - yangi qator qo'shilganda
  • 🟢 UPDATE Trigger - qator o'zgartirilganda
  • 🔴 DELETE Trigger - qator o'chirilganda
  • 🟣 TRUNCATE Trigger - jadval tozalanganda

Qachon ishlatiladi?

  • 📝 Tarix (history) saqlash uchun
  • ✅ Ma'lumotlarni tekshirish uchun
  • 🔔 Avtomatik xabarnomalar yuborish
  • 🔄 Boshqa jadvallarni yangilash
  • 📊 Statistika yig'ish

BEFORE vs AFTER

BEFORE - hodisa sodir bo'lishidan oldin ishlaydi (ma'lumotni o'zgartirish mumkin). AFTER - hodisa sodir bo'lgandan keyin ishlaydi.

Design Tools (DrawSQL, Draw.io)

DrawSQL

Database diagrammalarini yaratish uchun maxsus vosita. Vizual ravishda jadvallar va ularning bog'lanishlarini ko'rsatadi.

  • 🎨 Drag & Drop interfeysi
  • 🔗 Avtomatik bog'lanishlar
  • 📤 SQL kod eksport qilish
  • 👥 Jamoa bilan ishlash

Draw.io (diagrams.net)

Umumiy maqsadli diagramma yaratish vositasi. Database sxemalarini ham chizish mumkin.

  • 🆓 Bepul va ochiq manba
  • 💾 Turli formatlarda saqlash
  • 🔌 Google Drive integratsiyasi
  • 📱 Online va offline ishlash

Qanday ishlatiladi?

  • 1️⃣ Jadvallarni yarating
  • 2️⃣ Ustunlarni qo'shing (nom, tip, cheklovlar)
  • 3️⃣ Primary Key belgilang
  • 4️⃣ Foreign Key orqali bog'lang
  • 5️⃣ Diagrammani eksport qiling

Masala #1

Oson

Kitoblar do'koni uchun Trigger

Sizda 'books' jadvali bor. Har safar kitob sotilganda (count kamaytirilganda), 'sales_history' jadvaliga yozuv qo'shish kerak.

Masala #2

O'rta

Xodimlar ma'oshi kontroli

Xodimlar jadvaliga yangi xodim qo'shilayotganda, agar uning maoshi 0 yoki manfiy bo'lsa, xatolik berish kerak va qo'shilishiga yo'l qo'ymaslik kerak.

Masala #3

Qiyin

Mahsulotlar arxivi

Mahsulot o'chirilganda, uning barcha ma'lumotlari 'products_archive' jadvaliga ko'chirilishi va o'chirilgan sana ham yozilishi kerak.
