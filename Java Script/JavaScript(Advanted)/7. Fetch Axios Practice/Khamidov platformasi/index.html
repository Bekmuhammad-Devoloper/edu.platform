  • Fetch and Axios

    • 1️⃣ fetch nima?

      fetch – bu brauzer ichida mavjud bo‘lgan API, u serverdan ma’lumot olib kelish uchun ishlatiladi.
      👉 U Promise qaytaradi.
      Misol: API’dan ma’lumot olish 
                      // GET so'rovi
                fetch("https://jsonplaceholder.typicode.com/posts/1")
                  .then(res => res.json())   // javobni JSON ga aylantiramiz
                  .then(data => console.log("✅ Fetch natija:", data))
                  .catch(err => console.error("❌ Xato:", err))
      POST (yangi ma’lumot yuborish) 
                      fetch("https://jsonplaceholder.typicode.com/posts", {
                method: "POST",
                headers: {
                  "Content-Type": "application/json"
                },
                body: JSON.stringify({
                  title: "Salom",
                  body: "Bu fetch orqali yuborildi",
                  userId: 1
                })
              })
                .then(res => res.json())
                .then(data => console.log("✅ Yuborildi:", data))
                .catch(err => console.error(err))
    • 2️⃣ axios nima?
      axios – bu kutubxona (npm orqali o‘rnatiladi).
      U fetchdan qulayroq va ko‘proq imkoniyatlarga ega:
      JSON ni avtomatik o‘qiydi (res.data bilan ishlaysiz).
      Interceptorlar mavjud (token qo‘shish oson).
      Xatolarni boshqarish osonroq.
      👉 O‘rnatish: 
                      npm install axios
      GET misol 
                      import axios from "axios"

                axios.get("https://jsonplaceholder.typicode.com/posts/1")
                  .then(res => {
                    console.log("✅ Axios natija:", res.data)
                  })
                  .catch(err => {
                    console.error("❌ Xato:", err.message)
                  })
      POST misol 
                      axios.post("https://jsonplaceholder.typicode.com/posts", {
                  title: "Salom",
                  body: "Bu axios orqali yuborildi",
                  userId: 1
                })
                  .then(res => {
                    console.log("✅ Yuborildi:", res.data)
                  })
                  .catch(err => {
                    console.error(err)
                  })
      • Fetch va Axios farqlari:
      • JSON parse:
        • fetch → res.json() qilish kerak.
        • axios → res.data tayyor.
      • Kutubxona:
        • fetch → brauzerda bor.
        • axios → alohida o‘rnatish kerak.
      • Xato:
        • fetch → faqat internet xatoni ushlaydi.
        • axios → internet + server (status) xatolarni ham ushlaydi.
      • Qulayliklar:
        • fetch → oddiy imkoniyatlar.
        • axios → qo‘shimcha: interceptor, timeout, cancel, progress.

  • Amaliyot

    1. Maqsad

      JSONPlaceholder API bilan fetch() va axios orqali ishlash. Har ikkisi uchun async/await yondashuvi qo‘llanadi.

      API manzillari

      • GET — https://jsonplaceholder.typicode.com/posts
      • GET — https://jsonplaceholder.typicode.com/posts/1
      • POST — https://jsonplaceholder.typicode.com/posts
      • PUT — https://jsonplaceholder.typicode.com/posts/1
      • DELETE — https://jsonplaceholder.typicode.com/posts/1

      Talablar

      1. Har bir CRUD amalini (Create, Read, Update, Delete) alohida funksiya qilib yozish.
      2. Har bir funksiya ikki xil ko‘rinishda yozilsin: fetch va axios.
      3. Barcha funksiyalarda async/await ishlatilishi kerak.
      4. Xatolarni try/catch orqali ushlash va konsolga chiqarish.

      Natijani chiqarish

      • Har bir so‘rov muvaffaqiyatli bajarilganda: status kodi va JSON ma’lumot konsolga chiqarilsin.
      • Agar xato bo‘lsa, tushunarli xabar bilan konsolga yozilsin.

      POST/PUT uchun namunaviy body

      • title
      • body
      • userId

      Qiymatlar ixtiyoriy test ma’lumotlari bo‘lishi mumkin.

      async/await yondashuvi uchun qadamlar

      1. async funksiya yaratish.
      2. await fetch(url, options) yoki await axios.method(url, data) yordamida so‘rov yuborish.
      3. Statusni tekshirish va response.data yoki await res.json() natijasini olish.
      4. Natijani konsolga chiqarish.
      5. try/catch orqali xatolarni ushlash va konsolga yozish.

      Header va body talablari

      • POST/PUT da sarlavha: Content-Type: application/json.
      • JSON body: { title, body, userId }.

      Qo‘shimcha eslatmalar

      • DevTools → Console oynasini ochib natijalarni tekshirish.
      • Har bir CRUD amalida log yozing: amal nomi, status, va natija.

  • Uyga Vazifa

    1. Maqsad

      JSONPlaceholder API yordamida foydalanuvchilar (users) va ularning postlari bilan ishlovchi mini tizim yaratish. Har bir amal async/await yondashuvi bilan, ikkita usulda bajariladi: fetch va axios.

      API manzillari

      • GET — https://jsonplaceholder.typicode.com/users
      • GET — https://jsonplaceholder.typicode.com/users/1
      • POST — https://jsonplaceholder.typicode.com/users
      • PUT — https://jsonplaceholder.typicode.com/users/1
      • DELETE — https://jsonplaceholder.typicode.com/users/1
      • GET (user postlari) — https://jsonplaceholder.typicode.com/users/1/posts

      Talablar

      1. User CRUD (yaratish, olish, yangilash, o‘chirish) funksiyalarini yozish.
      2. Har bir user uchun postlar ro‘yxatini olish funksiyasini yozish.
      3. Har bir funksiya fetch va axios bilan yozilsin.
      4. Barcha funksiyalarda async/await va try/catch ishlatilishi shart.

      Natijani chiqarish

      • Har bir so‘rovdan keyin status kodi va natija konsolga yozilsin.
      • Xato bo‘lsa, tushunarli xabar chiqsin.

      POST/PUT uchun namunaviy body

      • name
      • username
      • email
      • phone
      • website

      Qiymatlar test uchun berilishi mumkin.

      Qo‘shimcha topshiriqlar

      • User yaratgandan so‘ng, uni user.id orqali postlar ro‘yxatini olib keling.
      • User yangilanganda, faqatgina name va email ni o‘zgartiring.
      • User o‘chirilgandan keyin, "User muvaffaqiyatli o‘chirildi" degan xabarni konsolga yozing.

      Qo‘shimcha eslatmalar

      • DevTools → Console’da natijalarni ko‘ring.
      • Funksiyalarning nomi aniq bo‘lsin: createUser(), getUsers(), updateUser(), deleteUser(), getUserPosts().
      • Ikkala yondashuv (fetch va axios) uchun alohida bo‘lim qiling.
