JavaScript

  • Event Loop

    • JavaScript bir oqimli (single-threaded) til
      Demak, u bir vaqtning o‘zida faqat bitta ishni bajaradi.
      Lekin biz asinxron (kechikadigan) ishlarni ham qilmoqchimiz: masalan, setTimeout, fetch, click event va hokazo.
    • Asosiy bo‘laklar
      JavaScript ishlash jarayoni quyidagilardan iborat:

      Call Stack (chaqiruv steki)
      – Bu joyda kodlar birma-bir bajariladi.
      – Masalan: oddiy console.log("Hello") shu yerda bajariladi.

      Web APIs (brauzerning API’lari)
      – Asinxron vazifalar (setTimeout, DOM events, fetch, va h.k.) shu yerda bajarilib, navbatga qo‘yiladi.

      Callback Queue (yoki Task Queue / Macrotask Queue)
      – Asinxron vazifalarning callback’lari shu yerga tushadi (masalan, setTimeout callback).

      Microtask Queue
      – Bu joyda Promise kabi “tezroq bajarilishi kerak” bo‘lgan ishlar turadi.
      – Microtask Queue Callback Queue’dan ustun!

      Event Loop
      – Bu “nazoratchi” bo‘lib, doimiy aylanib turadi:
      Call Stack bo‘sh bo‘lsa → Microtask Queue’dan vazifa olib bajaradi.
      Agar u ham bo‘sh bo‘lsa → Callback Queue’dan vazifa olib bajaradi.

    • Oddiy misol

                      console.log("1");

                setTimeout(() => {
                  console.log("2");
                }, 0);
                
                Promise.resolve().then(() => {
                  console.log("3");
                });
                
                console.log("4");

      natijalar:

      1
      4
      3
      2

      Izoh:
      1 → darhol stack’da bajariladi.
      setTimeout → Web APIs’ga yuboriladi → 0ms kutib → Callback Queue’ga tushadi.
      Promise.then → Microtask Queue’ga tushadi.
      4 → darhol bajariladi.
      Stack bo‘sh → Microtask Queue’dagi 3 bajariladi.
      Keyin Callback Queue’dagi 2 bajariladi.

  • Amaliyot

    1. Faktorial hisoblash

      Berilgan son uchun faktorialni hisoblash.

      Formula: n! = n × (n-1) × (n-2) × ... × 1

      Misol: 5! = 5 × 4 × 3 × 2 × 1 = 120

    2. Armstrong soni

      Berilgan son Armstrong soni ekanligini tekshirish.

      Ta’rif: Agar sonning raqamlari kubining yig‘indisi sonning o‘ziga teng bo‘lsa, u Armstrong soni deyiladi.

      Misol: 153 → 1³ + 5³ + 3³ = 153

    3. Palindrom

      Berilgan satrning palindrom ekanligini tekshirish (ya'ni orqaga qarab o‘qiganda ham bir xil bo‘lsa).

      Misol: "madam" → palindrom, "racecar" → palindrom

    4. Fibonaçchi qatori

      Fibonaçchi qatorining n-chi elementini hisoblash.

      Formula: F(0) = 0, F(1) = 1, F(n) = F(n-1) + F(n-2)

      Misol: F(5) = 5 (0, 1, 1, 2, 3, 5)

    5. Maxsus tugunlarni o‘qish

      Berilgan massivdan eng katta va eng kichik sonlarni topib, ular orasidagi farqni hisoblash.

      Misol: [2, 7, 1, 9] → eng katta = 9, eng kichik = 1, farq = 9 - 1 = 8

    6. Teskari massiv

      Berilgan massivni teskari qilib chiqarish.

      Misol: [1, 2, 3] → [3, 2, 1]

    7. Birinchi unikal belgini topish

      Berilgan satrda faqat bitta martalab uchraydigan eng birinchi belgini topish.

      Misol: "aabbc" → "c"

    8. Anagramma

      Ikki satrning anagramma ekanligini tekshirish (ya'ni, har bir satrdagi harflar bir xil bo‘lishi kerak).

      Misol: "listen" va "silent"

    9. Yig‘indi masalasi

      Berilgan massivdagi barcha juft sonlarning yig‘indisini hisoblash.

      Misol: [1, 2, 3, 4] → 2 + 4 = 6

    10. Harmonik sonlar

      Berilgan son uchun harmonik sonni hisoblash:

      Formula: H(n) = 1 + 1/2 + 1/3 + ⋯ + 1/n

      Misol: H(3) = 1 + 1/2 + 1/3

  • Uyga Vazifa

    1. Maqsad

      Fake Store API bilan fetch() orqali ishlash va natijalarni konsolga chiqarish. Bitta sahifada ikkita yondashuv ko‘rsatiladi: then() va async/await.

      API manzillari

      • GET — https://fakestoreapi.com/products
      • GET — https://fakestoreapi.com/products/1
      • POST — https://fakestoreapi.com/products
      • PUT — https://fakestoreapi.com/products/1
      • PATCH — https://fakestoreapi.com/products/1
      • DELETE — https://fakestoreapi.com/products/1

      Talablar

      1. Har bir endpoint uchun alohida so‘rov yuborish.
      2. So‘rovlarni ikki xil usulda ko‘rsatish: then() va async/await.
      3. Har bir so‘rov natijasini brauzer konsoliga chiqarish: muvaffaqiyatli javob va xatolar.
      4. POST, PUT, PATCH uchun JSON body yuborish va Content-Type: application/json sarlavhasini qo‘yish.
      5. DELETE so‘rovining javobini ham konsolga chiqarish.

      Natijani chiqarish

      • Muvaffaqiyatli javobda status kodini va JSON ma’lumotni konsolga yozish.
      • Xatolik bo‘lsa, xatoni tushunarli xabar bilan konsolga yozish.

      POST/PUT/PATCH uchun namunaviy ma’lumot tarkibi

      • title
      • price
      • description
      • image
      • category

      Qiymatlar ixtiyoriy test ma’lumotlari bo‘lishi mumkin.

      then() yondashuvi uchun qadamlar

      1. fetch(url, options) chaqirish.
      2. .then() ichida statusni tekshirish va res.json() qaytarish.
      3. Keyingi .then() ichida olingan obyektni konsolga chiqarish.
      4. .catch() orqali xatolarni ushlash va konsolga yozish.

      async/await yondashuvi uchun qadamlar

      1. async funksiya yaratish.
      2. await fetch(url, options) yordamida javobni olish.
      3. Statusni tekshirish va await res.json() natijasini konsolga chiqarish.
      4. try/catch orqali xatolarni ushlash va konsolga yozish.

      Header va body talablari

      • POST/PUT/PATCH da sarlavha: Content-Type: application/json.
      • JSON body: JSON.stringify({ title, price, description, image, category }).

      Qo‘shimcha eslatmalar

      • DevTools → Console oynasini ochib natijalarni ko‘ring.
      • Har bir endpoint bo‘yicha alohida log yozing: usul nomi (then yoki async), status, va ma’lumot.
      • Agar javob ok bo‘lmasa, mos xabar bilan xato tashlang.
