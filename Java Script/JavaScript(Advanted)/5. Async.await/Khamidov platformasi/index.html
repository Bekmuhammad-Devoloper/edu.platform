JavaScript

  • async/await

    1. 🔹 Asosiy G‘oya

      JavaScript’da 3 bosqichda asinxron ishlash mexanizmi rivojlangan:
      1. Callback (eski usul)
      2. Promise (zamonaviyroq)
      3. Async/Await (Promise’ning soddalashtirilgan ko‘rinishi)
    2. 1️⃣ Promise – poydevor Promise – bu kelajakdagi qiymatni bildiradi.
      Masalan, serverdan ma’lumot olish vaqt talab qiladi. Promise natijani keyinroq beradi. 
                  function getData() {
                return new Promise((resolve, reject) => {
                  setTimeout(() => {
              if(Math.random()>0.2){
                    resolve("✅ Ma’lumot keldi");
              }else{
                    reject("❌ Xatolik yuz berdi");} 
                  }, 2000);
                });
              }
              
              getData()
                .then((data) => console.log(data))
                .catch((err) => console.log(err));
    3. 2️⃣ Async/Await – Promiseni chiroyli yozish
      Bir xil ishni async/await bilan yozsak: 
                  function getData() {
                return new Promise((resolve) => {
                  setTimeout(() => resolve("✅ Ma’lumot keldi"), 2000);
                });
              }
              
              async function run() {
                try {
                  console.log("⏳ Kutilyapti...");
                  let result = await getData(); // Promise tugashini kutadi
                  console.log(result);
                  console.log("✔️ Tugadi");
                } catch (err) {
                  console.log("❌ Xato:", err);
                }
              }
              
              run();
    4. 3️⃣ Hayotiy misol bilan 
                  function haveBreakfast() {
                return new Promise((resolve) => {
                  setTimeout(() => resolve("🍳 Nonushta qildim"), 1000);
                });
              }
              
              function goToWork() {
                return new Promise((resolve) => {
                  setTimeout(() => resolve("🏢 Ishga bordim"), 2000);
                });
              }
              
              haveBreakfast()
                .then((msg) => {
                  console.log(msg);
                  return goToWork();
                })
                .then((msg) => console.log(msg));
    5. async/await bilan 
                  function haveBreakfast() {
                return new Promise((resolve) => {
                  setTimeout(() => resolve("🍳 Nonushta qildim"), 1000);
                });
              }
              
              function goToWork() {
                return new Promise((resolve) => {
                  setTimeout(() => resolve("🏢 Ishga bordim"), 2000);
                });
              }
              
              async function dailyRoutine() {
                let breakfast = await haveBreakfast();
                console.log(breakfast);
              
                let work = await goToWork();
                console.log(work);
              }
              
              dailyRoutine();
    6. 4️⃣ Parallel ishlash (Promise.all bilan)
      Ba’zan ikkita ish bir-biriga bog‘liq emas, parallel bajarish kerak. 
                function boilWater() {
                return new Promise((resolve) => setTimeout(() => resolve("💧 Suv qaynadi"), 2000));
              }
              function fryEggs() {
                return new Promise((resolve) => setTimeout(() => resolve("🍳 Tuxum qovurildi"), 1500));
              }
              
              async function breakfast() {
                let [water, eggs] = await Promise.all([boilWater(), fryEggs()]);
                console.log(water);
                console.log(eggs);
              }
              
              breakfast();
    7. Promise – kelajakdagi qiymatni qaytaradi.
      Async/Await – Promise bilan ishlashni soddalashtiradi.
      async → funksiya doim Promise qaytaradi.
      await → Promise tugashini kutib, natijani qaytaradi.
      try/catch → xatoni ushlash uchun ishlatiladi.
      Promise.all → parallel ishlash uchun.

  • Amaliyot (Promise or async/await)

    1. ✅ Vazifa 1: Login tekshiruvi (2 soniyalik kechikish bilan)

      Vazifa: Foydalanuvchi login-parolini tekshiradigan asinxron funksiya yozing.

      Shart:

      • Foydalanuvchi username va password kiritadi.
      • 2 soniyalik kechikishdan so‘ng tekshiruv bajariladi.
      • Agar parol "12345" bo‘lsa — konsolga "Login muvaffaqiyatli" chiqadi.
      • Aks holda — "Parol noto‘g‘ri" degan xatolik chiqadi.
      • Ushbu masalani 2 xil usulda yeching:
        • 1) Promise bilan (.then() va .catch() yordamida)
        • 2) async/await va try/catch yordamida
      • Ikkala usuldagi kod farqini solishtiring: qaysi biri toza, osonroq yoki tushunarliroq.

    2. ✅ Vazifa 2: Foydalanuvchining postlarini olish

      Vazifa: Berilgan foydalanuvchi ID bo‘yicha uning ma’lumotlari va postlarini olib chiqaring.

      Shart:

      • Foydalanuvchi ID (masalan, 1) beriladi.
      • Avval https://jsonplaceholder.typicode.com/users/1 orqali foydalanuvchi ma’lumotlarini oling.
      • So‘ng https://jsonplaceholder.typicode.com/posts?userId=1 orqali shu foydalanuvchining postlarini oling.
      • Konsolga quyidagilarni chiqaring:
        • Foydalanuvchining ismi
        • U yozgan barcha postlarning sarlavhalari
      • Masalani 2 xil usulda yeching:
        • 1) Promise (.then() zanjiri bilan)
        • 2) async/await bilan (try/catch ishlatib)
      • Ikkala usuldagi kod tuzilmasini solishtiring.

    3. ✅ Vazifa 3: Ob-havo ma’lumotini olish (simulyatsiya)

      Vazifa: Ob-havo ma’lumotini olib keladigan asinxron funksiya yozing.

      Shart:

      • Shahar nomi beriladi (masalan, "Tashkent").
      • Simulyatsiya sifatida ob-havo API’ga so‘rov yuborgandek 3 soniya kuting.
      • Kechikishdan so‘ng, iqlim ma’lumotini qaytaring (masalan, "25°C, Quyoshli").
      • Agar shahar nomi bo‘sh bo‘lsa — "Shahar nomi kiritilmadi" degan xatolik chiqaring.
      • Ushbu masalani 2 xil usulda yeching:
        • 1) Promise bilan (.then() va .catch() yordamida)
        • 2) async/await va try/catch yordamida
      • Har ikkala yechimda kod qanday yozilishini solishtiring.

  • Amaliyot(async/await)

    1. ✅ Vazifa 1: Timer bilan ishlash

      Vazifa: 3 soniyalik kechikishdan so‘ng "Vaqt tugadi!" degan xabarni konsolga chiqaring.

      Yo‘riqnoma:

      • setTimeout funksiyasini Promise ichiga joylang.
      • await yordamida 3 soniyani kuting.
      • Kechikish tugagach, konsolga "Vaqt tugadi!" deb chiqaring.

    2. ✅ Vazifa 2: Matematika amallarini bajarish

      Vazifa: Ikkita sonni qo‘shish va ko‘paytirish uchun alohida asinxron funksiyalar yarating.

      Yo‘riqnoma:

      • Qo‘shish uchun alohida async funksiya yarating.
      • Ko‘paytirish uchun ham shunday funksiya yarating.
      • await yordamida natijalarni kutib oling.
      • Natijalarni konsolga chiqarish kerak.

    3. ✅ Vazifa 3: Random raqam bilan ishlash

      Vazifa: 1 soniyadan so‘ng tasodifiy raqam qaytarsin. Raqam 50 dan katta bo‘lsa "Katta raqam!", kichik bo‘lsa "Kichik raqam!" deb chiqaring.

      Yo‘riqnoma:

      • Math.random() orqali 0 dan 100 gacha tasodifiy raqam yarating.
      • 1 soniyalik kechikish qo‘shing (Promise bilan).
      • Raqamni tekshirib, if yordamida kerakli matnni chiqaring.

    4. ✅ Vazifa 4: Maxsus va'da yaratuvchi funksiya

      Vazifa: Asinxron funksiya yarating, u 1 dan 5 soniyagacha bo‘lgan tasodifiy vaqtda natijani qaytarsin.

      Yo‘riqnoma:

      • Math.random() yordamida 1000–5000 ms orasida vaqt belgilang.
      • setTimeout yordamida va'dani bajaring.
      • await orqali kutib, konsolga natijani chiqaring.

    5. ✅ Vazifa 5: Oddiy login tizimi (simulyatsiya)

      Vazifa: Asinxron funksiya yozing, u foydalanuvchi nomi va parolni tekshiradi, va 2 soniyadan so‘ng natija beradi.

      Yo‘riqnoma:

      • async funksiya yarating va unga username hamda password yuboring.
      • 2 soniyalik kechikish qo‘shing (Promise bilan).
      • Agar password "12345" bo‘lsa — login muvaffaqiyatli, bo‘lmasa — muvaffaqiyatsiz deb chiqaring.

      Vazifa: Barcha postlar ichidan matni eng uzun bo‘lgan postni toping va uni muallifi bilan birga konsolga chiqaring.

    6. Oddiy Promise yaratish

      delay(ms) funksiyasini yozing, u berilgan millisekunddan keyin Promise qaytarsin.

      Masalan: delay(2000) keyin "2 soniya o'tdi" degan xabar chiqsin.

    7. Promise zanjiri yaratish

      fetchData() funksiyasini yozing, u 1 soniyadan keyin "Ma’lumot olindi" degan Promise qaytarsin.

      Natijani then() bilan konsolga chiqaring.

    8. Promise rad qilish

      checkNumber(num) funksiyasini yozing, u son juft bo‘lsa Promise resolve, toq bo‘lsa reject qilsin.

      Natijani then() va catch() bilan konsolga chiqaring.

    9. Promise.all() ishlatish

      task1(), task2(), task3() funksiyalarini yozing, har biri turli vaqtda bajariladigan Promise qaytarsin.

      Promise.all() yordamida barchasini kuting va natijani konsolga chiqaring.

    10. Promise.race() ishlatish

      task1, task2, task3 funksiyalaridan foydalanib, Promise.race() dan foydalaning.

      Eng tez bajarilgan Promise natijasini konsolga chiqaring.

    11. API chaqiruvi bilan Promise yaratish

      fetchUserData() funksiyasini yozing.

      U https://jsonplaceholder.typicode.com/users/1 dan foydalanuvchi ma’lumotini olib, ismini konsolga chiqarsin.

    12. setTimeout yordamida Promise yaratish

      wait(ms) funksiyasini yozing, u berilgan vaqt o'tgach Promise qaytarsin.

      Masalan: wait(3000) keyin "3 soniya o'tdi" degan xabar chiqsin.
