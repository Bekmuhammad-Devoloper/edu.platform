  • OOP

    1. OOP- bu Object Oriented Programming sozlarini qisqartmasi.
      Yani bu Obyektga Yonaltirilgan Dasturlash degani.

    2. OOP nima uchun kerak?
      Oddiy dasturlashda kodlar bir joyda yigilib ketadi, tushunish qiyin boladi. OOP esa kodlarni obyektlar va klasslar yordamida tartibli va tushunarli qiladi.

    3. Bunga misol qilib avtomabil zavodini olsak boladi:
      Har bir avtomobil bir obyekt.
      Avtomobil zavodi — bu shablon (klass).
      Shu shablondan 1000 ta mashina yasash mumkin.

    4. Obyekt (Object) nima?
      Obyekt — bu ma’lumot (xususiyatlar) va harakatlar (metodlar) yig‘indisi. 

                      const car = {
                brand: "BMW",
                color: "qora",
                drive: function() {
                  console.log("BMW haydalmoqda...");
                }
              };
              
              car.drive(); 
              
              //consoleda
              // BMW haydalmoqda...

  • OOP Principles

      OOP 4 ta asosiy tamoyilga tayanadi:

    1. Encapsulation (Yashirish) — kodni "ichkarida" boshqarish.
    2. Abstraction (Abstraktsiya) — keraksiz detallarni yashirish, faqat keraklisini ko‘rsatish.
    3. Inheritance (Meros olish) — bir klassdan boshqasini hosil qilish.
    4. Polymorphism (Ko‘p shakllilik) — metodlar turli klasslarda har xil ishlashi.

  • Amaliyot(Object)


    1. phone nomli obyekt yarating.
      brand, model, price xususiyatlari bo‘lsin.
      call() nomli metod bo‘lib, "Calling from [brand] [model]" degan xabar chiqarsin.

    2. student nomli obyekt yarating.
      name, age, grade xususiyatlari bo‘lsin.
      study() metodi bo‘lib, "[name] dars qilmoqda" degan xabar chiqarsin.

    3. book nomli obyekt yarating.
      title, author, pages xususiyatlari bo‘lsin.
      info() metodi bo‘lib, "[title], muallif: [author], [pages] bet" degan xabar chiqarsin.

    4. computer nomli obyekt yarating.
      brand, cpu, ram xususiyatlari bo‘lsin.
      run() metodi bo‘lib, "[brand] ishlamoqda" degan xabar chiqarsin.

    5. movie nomli obyekt yarating.
      name, year, genre xususiyatlari bo‘lsin.
      details() metodi bo‘lib, "[name] ([year]) - [genre]" degan xabar chiqarsin.

    6. animal nomli obyekt yarating.
      name, type, sound xususiyatlari bo‘lsin.
      makeSound() metodi bo‘lib, "[name] [sound] ovoz chiqardi" degan xabar chiqarsin.

  • Amaliyot(Settor and getter function)

    1. 1-masala: Book klassi
      Vazifa:
      Book nomli class yozing. U quyidagi propertylarga ega bo‘lsin:
      ● title
      ● author
      ● year
      Quyidagi metodlarni yozing:
      ● getSummary() – kitob haqida qisqacha ma’lumot qaytaradi:
      "BookName by AuthorName, published in Year"
      Bonus:
      ● age getter yarating – kitob nechanchi yil oldin chop etilganini qaytarsin.
    2. 2-masala: Rectangle klassi
      Vazifa:
      Rectangle nomli class yozing. Quyidagilar bo‘lsin:
      ● width
      ● height
      Methodlar:
      ● getArea() – yuzani qaytaradi
      ● getPerimeter() – perimetrni qaytaradi
      Setter:
      ● setWidth() – eni o‘zgartiradi
      ● setHeight() – bo‘yini o‘zgartiradi
    3. 3-masala: User klassi
      Vazifa:
      User nomli class yarating. Property:
      ● firstName
      ● lastName
      ● email
      Method:
      ● getFullName() – to‘liq ism qaytaradi
      Getter:
      ● emailDomain – email domenini qaytarsin (masalan, agar email = "test@gmail.com" bo‘lsa, gmail.com ni qaytaradi)
    4. 4-masala: Product klassi
      Vazifa:
      Product nomli class yozing. Property:
      ● name
      ● price
      ● discount
      Method:
      ● getPriceWithDiscount() – chegirmali narxni hisoblab qaytaradi
      Setter:
      ● setDiscount() – yangi chegirma qiymatini belgilaydi
    5. 5-masala: Car klassi
      Vazifa:
      Car nomli class yozing. Property:
      ● brand
      ● model
      ● year
      Method:
      ● getCarInfo() – "Brand Model, Year" qaytaradi
      Bonus:
      ● age getter – mashina nechanchi yil oldin chiqarilganini qaytaradi.
