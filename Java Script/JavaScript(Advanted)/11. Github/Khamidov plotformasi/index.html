  • Git and GitHub

    • Git dasturini o'rnatish:

      1. Brauzeringizda git-scm.com manziliga o'ting. Bu Gitning rasmiy veb-sayti.
      2. Saytning bosh sahifasida sizning operatsion tizimingiz (Windows, macOS yoki Linux) uchun mos keladigan "Download" (Yuklab olish) tugmasini toping va uni bosing. Git avtomatik ravishda operatsion tizimingizni aniqlaydi va sizga mos versiyani taklif qiladi.
      3. Agar Windows operatsion tizimidan foydalanayotgan bo'lsangiz, "64-bit Git for Windows Setup" (64-bitli Windows uchun Git o'rnatish) faylini yuklab olishingiz kerak bo'ladi.

        Agar macOS operatsion tizimidan foydalanayotgan bo'lsangiz, Homebrew yoki MacPorts orqali o'rnatish tavsiya etiladi. Veb-saytda barcha kerakli ko'rsatmalar mavjud.

        Agar Linux operatsion tizimidan foydalanayotgan bo'lsangiz, terminalda buyruqlar yordamida o'rnatish eng oson yo'li hisoblanadi (masalan, Debian/Ubuntu uchun sudo apt-get install git).
      4. Yuklab olingan .exe (Windows uchun) yoki .dmg (macOS uchun) faylini toping va ustiga ikki marta bosing. Bu o'rnatish jarayonini boshlaydi.
      5. O'rnatish oynasidagi ko'rsatmalarga rioya qiling. Ko'pincha, hech narsani o'zgartirmasdan, faqatgina "Next" (Keyingi) tugmasini bosib o'tish kifoya. O'rnatish jarayoni sizga turli xil sozlamalarni taklif qilishi mumkin, lekin yangi foydalanuvchilar uchun standart sozlamalar eng maqbul hisoblanadi.
      6. Terminal (macOS/Linux) yoki Command Prompt / Git Bash (Windows) dasturini oching. Quyidagi buyruqni kiriting va Enter tugmasini bosing: 
        git --version
        Agar terminalda Gitning versiyasi ko'rinsa (masalan, git version 2.37.1), demak, dastur muvaffaqiyatli o'rnatilgan.

      • GitHub Account ochish:

      1. Brauzeringizda github.com manziliga o'ting.
        Saytning bosh sahifasining yuqori o'ng burchagida joylashgan "Sign up" tugmasini bosing.
      2. Elektron pochta manzili: Aktiv elektron pochta manzilingizni kiriting. Bu manzil orqali sizga tasdiqlash xabarlari keladi.

        Parol: Kuchli parol o'ylab toping. Parolingizda harflar, raqamlar va belgilar (simvollar) bo'lsa, xavfsizroq bo'ladi.

        Foydalanuvchi nomi (Username): O'zingizga qulay va boshqa foydalanuvchilarda takrorlanmaydigan ism tanlang. Masalan, ali-dev, vali-coder kabi.

        Elektron pochta xabarlari: "Product updates" (Mahsulot yangilanishlari) haqida ma'lumot olishni istasangiz, tasdiqlash katakchasiga belgi qo'ying.
      3. Sahifadagi ko'rsatmalarga amal qilib, robot emasligingizni isbotlang. Bu odatda biror rasmni tanlash yoki boshqa bir oddiy vazifani bajarish orqali amalga oshiriladi.
      4. Ro'yxatdan o'tishni yakunlash uchun elektron pochtangizga kirib, GitHub'dan kelgan tasdiqlash xabarini toping.

        Xabardagi "Verify email address" (Elektron pochtani tasdiqlash) tugmasini bosing. Bu sizni yana GitHub saytiga qaytaradi va akkauntingiz to'liq aktivlashadi.

  • Repository (Private or Public)

      • Repository: Private (shaxsiy) va Public (ommaviy)

      1. Git va GitHub'da "repository" (repo) bu sizning loyihangiz fayllari saqlanadigan joy. Bu loyihaning barcha versiyalari, o'zgarishlari va tarixi yozib boriladigan omborxona. Repositoriy yaratishda uni Private (shaxsiy) yoki Public (ommaviy) qilish imkoniyati mavjud.
      2. Public (Ommaviy) Repository:

        Bu repodagi kodni hamma ko'rishi mumkin.

        Sizning profilingizga kirgan har qanday odam ushbu loyihani ko'ra oladi, yuklab oladi yoki o'z loyihasida foydalanishi mumkin.

        Bu repolar ochiq kodli (open-source) loyihalar uchun juda qulay. Agar siz o'z ishingizni butun dunyo bilan bo'lishmoqchi bo'lsangiz yoki portfoliongizni ko'rsatmoqchi bo'lsangiz, uni public qilib yaratishingiz kerak.

        Boshqa dasturchilar sizning loyihangizga hissa qo'shish (contribution) imkoniyatiga ega bo'ladi.
      3. Private (Shaxsiy) Repository:

        Bu repodagi kodni faqat siz va siz ruxsat bergan odamlar ko'ra oladi.

        Kodni faqat siz yoki siz loyihaga qo'shgan hamkorlar (collaborators) ko'ra oladi, tahrirlay oladi va boshqara oladi.

        Bu repolar maxfiy loyihalar, kompaniya ichki kodlari yoki shaxsiy o'quv ishlari uchun juda qulay.

      • Lokal kodni GitHub'ga joylash:

      1. GitHub akkauntingizga kiring.

        Bosh sahifaning yuqori o'ng burchagidagi '+' belgisini bosing va "New repository" ni tanlang.

        "Repository name" (Repository nomi) bo'limiga loyihangiz uchun nom kiriting (masalan, my-first-project).

        Public yoki Private ekanligini tanlang. Agar o'quv loyihasi bo'lsa, Public qilish yaxshi tanlov.

        "Create repository" tugmasini bosing.
      2. Loyihangiz papkasiga o'ting. Agar VScodedan foydalansangiz, Terminalni oching.

        Quyidagi buyruqlarni ketma-ket kiriting:

        Loyihangizda Git'ni ishga tushiring: 
        git init
        Barcha fayllarni Git'ga qo'shing: 
        git add .
        O'zgarishlarga izoh (commit) bering: 
        git commit -m "First commit"
        "First commit" o'rniga istalgan izohni yozishingiz mumkin.
      3. GitHub'da yaratgan repoingiz sahifasiga qayting. U yerda sizga "…or push an existing repository from the command line" bo'limida ikkita buyruq ko'rsatiladi. Ularni nusxalash tugmasi orqali nusxalab oling. Buyruqlar taxminan quyidagicha bo'ladi:

        Lokal repoga masofaviy (remote) manzilni qo'shish: 

        git remote add origin https://github.com/SizningIsmingiz/loyihangiz-nomi.git
        Fayllarni GitHub'ga yuklash: 

                                            
                                        git branch -M main
                                        git push -u origin main
        Ushbu ikkala buyruqni ham terminalga joylab, Enter tugmasini bosing.

  • Celebration

    • GitHub'da "Collaborator" (Hamkor) qo'shish va birgalikda ishlash

      1. Private repository yaratish GitHub akkauntingizga kiring.

        Bosh sahifaning yuqori o'ng burchagidagi '+' tugmasini bosib, **"New repository"**ni tanlang.

        Repository nomini kiriting (masalan, private-team-project).

        "Private" variantini tanlang.

        "Create repository" tugmasini bosing.

    • Repoga hamkor (collaborator) qo'shish

      1. Yangi yaratilgan repongizga o'ting.

        Yuqori qatordagi tugmalar orasidan "Settings" (Sozlamalar) bo'limiga kiring.

        Chap tomondagi menyudan **"Collaborators and teams"**ni tanlang.

        "Add collaborator" tugmasini bosing.

        O'zingizning sherigingizning GitHub foydalanuvchi nomini (username) kiriting va uni ro'yxatdan topib, tanlang.

        "Add [username] to this repository" tugmasini bosing.

    • Sherik rolida ishlash:

      1. Sherik o'zining terminalini (yoki Git Bash'ni) ochadi.

        GitHub'dagi repoga o'tadi va kodni klonlash uchun HTTPS manzilini nusxalaydi.

        Terminalga quyidagi buyruqni kiritadi: 
        git clone https://github.com/SizningIsmingiz/private-team-project.git
        Bu buyruq loyihaning to'liq nusxasini uning kompyuteriga yuklab oladi.

    • Kodga o'zgarish kiritish va repoga joylash (push)

      1. Sherik klon qilingan papkaga kiradi va kodga o'zgarish kiritadi (masalan, index.html fayliga biror matn qo'shadi).

        O'zgarishlarni Git'ga qo'shish uchun terminalda quyidagi buyruqlarni ketma-ket kiritadi: 

        git add .
        Bu o'zgartirilgan fayllarni "sahnalashtirish" (staging area) qismiga qo'shadi.
        O'zgarishlarga izoh beradi: 

        git commit -m "Sherik tomonidan kiritilgan o'zgarishlar"
        O'zgartirilgan kodni GitHub'dagi repoga yuklaydi: 
        git push origin main
        Yoki sizda asosiy (default) filial nomi master bo'lishi ham mumkin. Bu holda git push origin master buyrug'i ishlatiladi.

  • Amaliyot

    • GitHub'da hamkorlikda ishlash

      Ushbu amaliy mashg'ulotda siz shaxsiy (private) repository bilan ishlash, undan kodni kompyuteringizga yuklab olish (clone), masalalarni yechish, o'zgarishlarni qayta yuklash (push) va shu jarayonda commit izohida ismingizni yozish ko'nikmalarini oshirasiz.

      Yechilishi kerak bo'lgan masalalar:

      1. Berilgan sonni tub sonligini tekshirish

        Kirish: 7

        Natija: true

      2. Massivdagi ikkinchi eng katta sonni topish

        Kirish: [3, 5, 7, 2, 8]

        Natija: 7

      3. Stringda eng ko'p qatnashgan harfni topish

        Kirish: "javascript"

        Natija: "a"

      4. Massivdagi barcha juft sonlar yig'indisini hisoblash

        Kirish: [1, 2, 3, 4, 5, 6]

        Natija: 12

      5. Massivdagi barcha kombinatsiyalarni (subsetlarni) chiqarish

        Kirish: [1, 2]

        Natija: [[], [1], [2], [1, 2]]

      6. Matndan faqat unli harflarni olib qolish

        Kirish: "salom dunyo"

        Natija: "aouo"

        Izoh: Faqat a, o, u, e, i harflarini qoldiring (katta va kichik harflarni hisobga oling).

      7. Stringdagi barcha raqamlar yig'indisini hisoblash

        Kirish: "a1b2c3"

        Natija: 6

      8. Massivni aylantirish (rotate)

        Kirish: [1, 2, 3, 4, 5], k = 2

        Natija: [4, 5, 1, 2, 3]

        Izoh: Har bir elementni o'ngga k marta siljiting.

      9. So'zlar sonini hisoblash

        Kirish: "Bugun havo juda yaxshi."

        Natija: 4

      10. Massivdagi eng kichik sonni topish

        Kirish: [8, 3, 5, 1, 9]

        Natija: 1

  • Uyga vazifa

    • OOP prinsiplari asosida hamkorlikda ishlash

      Ushbu amaliy mashg'ulotda siz Object-Oriented Programming (OOP) prinsiplaridan foydalangan holda masalalarni yechasiz va natijalarni shaxsiy (private) repositoryga joylaysiz.

      Yakuniy qadamda esa repoga Bekmuhammad-Devoloper akkauntini hamkor (collaborator) sifatida qo'shasiz.

      Yechilishi kerak bo'lgan masalalar:

      1. Inkapsulyatsiya (Encapsulation)

        Masala: Foydalanuvchi ma'lumotlarini (ismi, yoshi, paroli) saqlaydigan `User` klassini yarating. Foydalanuvchi yoshini tashqi tomondan to'g'ridan-to'g'ri o'zgartirishning oldini oling.

        Talab: `User` klassida `name` va `age` uchun public getter metodlar (masalan, `getName()`, `getAge()`) va faqat `age` uchun private setter metod yaratib, yoshni faqat konstruktor orqali o'rnatishni ta'minlang.

      2. Vorislash (Inheritance)

        Masala: Avtomobillar haqida ma'lumot saqlaydigan `Car` klassini yarating (`make`, `model`, `year` xususiyatlari bilan). Keyin `ElectricCar` nomli yangi klassni `Car` klassidan voris qilib oling va unga `batteryRange` nomli qo'shimcha xususiyat qo'shing.

        Talab: `Car` va `ElectricCar` klasslarini yaratib, har birida ma'lumotlarni konsolga chiqaruvchi metod (masalan, `displayInfo()`) yozing.

      3. Polimorfizm (Polymorphism)

        Masala: Turli hayvonlar ovozini chiqaradigan tizim yarating.

        Talab: `Animal` nomli asosiy klass yarating. Keyin `Dog` va `Cat` klasslarini `Animal`dan voris qilib oling. Har bir klassda `makeSound()` metodini yarating, lekin ularning ichki mantiqi har xil bo'lsin (masalan, it uchun "woof", mushuk uchun "meow" qaytarsin).

      4. Abstraksiya (Abstraction)

        Masala: Bank hisoblarini boshqarish uchun tizim yarating.

        Talab: `BankAccount` nomli abstrakt klass yarating, uning ichida `deposit(amount)` (pul qo'yish) va `withdraw(amount)` (pul yechish) kabi metodlar mavjud bo'lsin. So'ngra `SavingsAccount` (jamg'arma hisob) klassini `BankAccount`dan voris qilib olib, bu abstrakt metodlarni implementatsiya qiling.
