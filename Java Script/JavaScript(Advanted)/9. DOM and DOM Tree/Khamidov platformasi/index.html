  • DOM and DOM Tree

    • DOM nima?
      DOM (Document Object Model) – bu HTML (yoki XML) hujjatning obyektlar ko‘rinishidagi modeli.
      HTML kodni brauzer o‘qiydi.
      Uni daraxt (tree) shaklida tuzadi.
      JavaScript orqali biz shu daraxtdagi elementlarni ko‘ramiz, o‘zgartiramiz yoki ularga qo‘shimcha qo‘shamiz.

      👉 Oddiy qilib aytganda:
      HTML – uy qurilish loyihasi
      DOM – uyning qurilib bo‘lingan modeli
      JavaScript – usta (uyni o‘zgartiradi: devor rangini bo‘yab beradi, eshik qo‘yadi, oynani almashtiradi).

                  <p>Paragraf 2</p>

                  <script>
                    // 1) getElementById → ID orqali faqat bitta element topadi
                    const h1 = document.getElementById("sarlavha")
                    h1.textContent = "ID orqali o‘zgartirildi!"
                    h1.style.color = "blue"
                
                    // 2) getElementsByTagName → teg nomi bo‘yicha hamma elementlarni topadi
                    const paragraphs = document.getElementsByTagName("p")
                    for (let i = 0; i < paragraphs.length; i++) {
                      paragraphs[i].style.color = "red"
                      paragraphs[i].textContent = "Paragraf " + (i + 1) + " o‘zgartirildi!"
                    }
                
                    // 3) getElementsByClassName → class nomi bo‘yicha elementlarni topadi
                    const fruits = document.getElementsByClassName("fruit")
                    for (let i = 0; i < fruits.length; i++) {
                      fruits[i].style.color = "green"
                      fruits[i].style.fontWeight = "bold"
                      fruits[i].textContent = "Meva: " + fruits[i].textContent
                    }
                  </script>

    • 1️⃣ HTML Elementlarini o‘zgartirish

      a) element.innerHTML

      👉 Biror elementning ichidagi HTML kodini o‘zgartiradi.

      
            <p id="demo">Eski matn</p>
            
            <script>
              const p = document.getElementById("demo")
              p.innerHTML = "<b>Yangi matn</b>"  // ichiga yangi HTML yozildi
            </script>
      ✅ Natija: `

      Yangi matn

      ` ---
      b) element.attribute = new value

      👉 Elementning atributini bevosita o‘zgartirish.

      
            <img id="rasm" src="old.png">
            
            <script>
              const img = document.getElementById("rasm")
              img.src = "new.png"   // src atributi o‘zgartirildi
            </script>
      ---
      c) element.style.property = value

      👉 CSS uslubini (style) o‘zgartirish.

      
            <p id="matn">Matn</p>
            
            <script>
              const p = document.getElementById("matn")
              p.style.color = "red"      // qizil rang
              p.style.fontSize = "24px"  // kattaligi 24px
            </script>
      ---
      d) element.setAttribute(attribute, value)

      👉 Atribut qo‘shish yoki o‘zgartirish.

      
            <a id="link">Havola</a>
            
            <script>
              const a = document.getElementById("link")
              a.setAttribute("href", "https://google.com")
              a.setAttribute("target", "_blank") // yangi tabda ochiladi
            </script>
      ---

      2️⃣ Element qo‘shish va o‘chirish

      a) document.createElement(element)

      👉 Yangi HTML element yaratadi.

      
            <ul id="list">
              <li>Olma</li>
            </ul>
            
            <script>
              const ul = document.getElementById("list")
              const newItem = document.createElement("li") // yangi <li> yaratildi
              newItem.innerHTML = "Banan"
              ul.appendChild(newItem) // ro‘yxatga qo‘shildi
            </script>
      ✅ Natija: Olma Banan ---
      b) document.removeChild(element)

      👉 Elementni o‘chirish.

      
            <ul id="list">
              <li id="first">Olma</li>
              <li>Banan</li>
            </ul>
            
            <script>
              const ul = document.getElementById("list")
              const first = document.getElementById("first")
              ul.removeChild(first)   // Olma o‘chirildi
            </script>
      ✅ Natija: Banan ---
      c) document.appendChild(element)

      👉 Elementni ota elementga qo‘shish.

      
            <div id="box"></div>
            
            <script>
              const box = document.getElementById("box")
              const p = document.createElement("p")
              p.innerHTML = "Salom, yangi paragraf!"
              box.appendChild(p)   // <div> ichiga qo‘shildi
            </script>
      ---
      d) document.replaceChild(new, old)

      👉 Eski elementni yangisi bilan almashtirish.

      
            <ul id="list">
              <li id="old">Olma</li>
            </ul>
            
            <script>
              const ul = document.getElementById("list")
              const oldItem = document.getElementById("old")
            
              const newItem = document.createElement("li")
              newItem.innerHTML = "Banan"
            
              ul.replaceChild(newItem, oldItem)  // Olma o‘rniga Banan
            </script>
      ✅ Natija: Banan ---
      e) document.write(text)

      👉 HTMLni to‘g‘ridan-to‘g‘ri sahifaga yozadi.

      ⚠️ Diqqat: document.write() sahifa yuklangandan keyin ishlatilsa, butun sahifani o‘chirib tashlaydi va faqat yozilgan matn qoladi. 
      
            <script>
              document.write("<h4>Salom!</h4>")
            </script>
      ✅ Sahifaga: `

      Salom!

      ` ---
      🔑 Xulosa
      • innerHTML → element ichidagi HTML kodni o‘zgartiradi.
      • attribute yoki setAttribute → atributlarni o‘zgartiradi.
      • style.property → CSS xossasini o‘zgartiradi.
      • createElement → yangi element yaratadi.
      • appendChild → yangi element qo‘shadi.
      • removeChild → elementni o‘chiradi.
      • replaceChild → elementni yangisi bilan almashtiradi.
      • document.write → sahifaga yozadi (kam ishlatiladi).

    • 🔹 1. querySelector va querySelectorAll

      👉 Eng qulay metodlar, ular orqali CSS selektor bo‘yicha element tanlash mumkin.
      
            <p class="test">Matn 1</p>
            <p class="test">Matn 2</p>
            
            <script>
              const firstP = document.querySelector(".test")  
              // faqat 1-ta element oladi
              firstP.style.color = "red"
            
              const allP = document.querySelectorAll(".test")  
              // barcha elementlarni oladi
              allP.forEach(el => el.style.fontWeight = "bold")
            </script>

      🔹 2. parentNode, children, firstChild, lastChild

      👉 Elementlarning ota-ona va farzandlarini olish.
      
            <div id="box">
              <p>Paragraf 1</p>
              <p>Paragraf 2</p>
            </div>
            
            <script>
              const box = document.getElementById("box")
              console.log(box.children)     // [<p>Paragraf 1</p>, <p>Paragraf 2</p>]
              console.log(box.firstChild)   // birinchi bola
              console.log(box.lastChild)    // oxirgi bola
              console.log(box.parentNode)   // ota element
            </script>

      🔹 3. innerText vs textContent

      👉 Ikkalasi ham matnni olish va o‘zgartirish uchun ishlatiladi, lekin farqi bor:
      • innerText → faqat ko‘rinadigan matnni qaytaradi.
      • textContent → yashirin (hidden) matnni ham oladi.
      
            <p id="demo">Salom <span style="display:none">Yashirin</span></p>
            
            <script>
              const el = document.getElementById("demo")
              console.log(el.innerText)    // "Salom"
              console.log(el.textContent)  // "Salom Yashirin"
            </script>

      🔹 4. Eventlar (onClick, addEventListener)

      👉 DOMdagi eng muhim qismi — hodisalar (eventlar).
      
            <button id="btn">Bos!</button>
            
            <script>
              const btn = document.getElementById("btn")
            
              // Usul 1
              btn.onclick = () => alert("Bosildi!")
            
              // Usul 2 (tavsiya etiladi)
              btn.addEventListener("click", () => {
                alert("addEventListener ishladi!")
              })
            </script>

      🔹 5. classList bilan ishlash

      👉 Elementning classlarini boshqarish uchun.
      
            <p id="matn" class="red">Salom</p>
            
            <script>
              const p = document.getElementById("matn")
              p.classList.add("big")       // yangi class qo‘shadi
              p.classList.remove("red")    // classni o‘chiradi
              p.classList.toggle("blue")   // yo‘q bo‘lsa qo‘shadi, bo‘lsa o‘chiradi
            </script>

      🔹 6. cloneNode()

      👉 Elementni nusxalash.
      
            <ul id="list">
              <li>Olma</li>
            </ul>
            
            <script>
              const li = document.querySelector("li")
              const newLi = li.cloneNode(true)  // ichidagi bilan birga nusxa oladi
              document.getElementById("list").appendChild(newLi)
            </script>
            
            ✅ Natija:
            Olma
            Olma

      🔹 7. Traversing – qo‘shni elementlarga o‘tish

      👉 Biroz professionalroq ishlarda kerak bo‘ladi.
      
            <ul>
              <li id="first">Olma</li>
              <li>Banan</li>
              <li>Uzum</li>
            </ul>
            
            <script>
              const first = document.getElementById("first")
              console.log(first.nextElementSibling)  // Banan
              console.log(first.previousElementSibling) // null (oldin element yo‘q)
            </script>

      🔑 Xulosa

      • Elementlarni tanlash → getElementById, querySelector, getElementsByClassName
      • O‘zgartirish → innerHTML, textContent, style, setAttribute
      • Qo‘shish/o‘chirish → createElement, appendChild, removeChild, replaceChild
      • Eventlar → onclick, addEventListener
      • Navigatsiya → parentNode, children, nextElementSibling, previousElementSibling
      • Classlar bilan ishlash → classList.add, classList.remove, classList.toggle
      • Nusxalash → cloneNode()
