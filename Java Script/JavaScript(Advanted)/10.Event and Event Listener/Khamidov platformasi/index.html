  • Event and Event Listener

    1. Event nima?

      Event (hodisa) — bu foydalanuvchi yoki brauzerda sodir bo‘ladigan voqea.
      Masalan:

      click – foydalanuvchi tugmani bosdi
      input – foydalanuvchi inputga ma’lumot kiritdi
      submit – forma yuborildi
      keydown – klaviaturada tugma bosildi
      load – sahifa to‘liq yuklandi
      Oddiy qilib aytganda: event bu trigger (signal).
    2. Event Listener nima?

      Event listener (hodisaga quloq soluvchi) — bu event sodir bo‘lganda nima qilish kerakligini aytadigan kod.
      ⚡ Format: 

      element.addEventListener("eventNomi", function)

      element → qaysi elementda hodisa kuzatiladi
      "eventNomi" → qaysi eventga quloq solamiz (click, input, submit, …)
      function → hodisa sodir bo‘lganda bajariladigan funksiya
    3. Oddiy misol 
      
                <button id="myBtn">Meni bos!</button>
                
                <script>
                  const btn = document.getElementById("myBtn");
                
                  // Event Listener qo‘shish
                  btn.addEventListener("click", () => {
                    alert("Siz tugmani bosdingiz!");
                  });
                </script>
      Bu yerda:
      Hodisa (event) → click
      Tinglovchi (event listener) → addEventListener
      Amal → alert chiqishi
    4. Xulosa
      1. Event → hodisa (click, input, submit, …)
      2. Event Listener → hodisani tinglab, bajariladigan amalni belgilaydi
      3. event object (e) → hodisa haqida ma’lumot beradi
