JavaScript

  • Instanceof

    1. Instanceof
      instanceof — bu JavaScript’da obyektning ma’lum bir klass (yoki konstruktor) asosida
      yaratilganini tekshiruvchi operator hisoblanadi.

    2. Code orali to'liq tushuncha.

              class Animal {}
        class Dog extends Animal {}
                                    
        const dog = new Dog();
                                    
        console.log(dog instanceof Dog);    // true
        console.log(dog instanceof Animal); // true (chunki Dog → Animal'dan meros olgan)

    3. ✅ Qachon ishlatiladi?
      Obyektni qaysi klassdan yaratilganini aniqlash uchun.
      Polimorfizm, xatoliklarni aniqlash yoki turga qarab harakat qilish kerak bo'lganda.

  • Mixin

    1. 🎯 Oddiy ta’rif:
      Mixin — bu alohida klass bo‘lmagan, ammo boshqa klasslarga xususiyat (metod) qo‘shish
      uchun ishlatiladigan obyekt yoki funksiya.

    2. 🧠 Nega kerak?
      JavaScript class A extends B tarzida faqat bitta klassdan meros ola oladi. Lekin
      agar siz bir nechta klassning metodlarini olishni istasangiz — mixin ishlatiladi.

    3. 🧪 Misol bilan tushuntirish:
      1️⃣ Ikkita alohida funksionallik:

              let canWalk = {
        walk() {
        console.log(${this.name} yurmoqda);
                }
            };
        
        let canEat = {
            eat() {
                console.log(${this.name} ovqat yemoqda);
                    }
            };

      2️⃣ Klassga mixinlarni qo‘shamiz:

              class Person {
            constructor(name) {
            this.name = name;
                }
            }
         // mixinlarni Person prototipiga qo‘shamiz
        Object.assign(Person.prototype, canWalk, canEat);
        
        const user = new Person("Ali");
        user.walk();  // Ali yurmoqda
        user.eat();   // Ali ovqat yemoqda

    4. 🔄 Mixin funksiyalar shaklida ham bo'lishi mumkin:

              function sayHiMixin(Base) {
        return class extends Base {
        sayHi() {
          console.log(Salom, men ${this.name});
                }
              };
            }
        
        class Student {
          constructor(name) {
            this.name = name;
              }
        }
        
        class SmartStudent extends sayHiMixin(Student) {}
        
        const s = new SmartStudent("Bekzod");
        s.sayHi(); // Salom, men Bekzod

    5. ✅ Foydali joylari:
      Katta loyihalarda kodni qayta ishlatish imkonini beradi.
      Bir nechta klassdan bir vaqtning o‘zida metodlar olish uchun ishlatiladi.
      DRY prinsipiga (Don't Repeat Yourself) amal qilishga yordam beradi.

  • Error Handling(Try, Catch and Finally)

    1. 🧠 Nima uchun "xato"ni boshqarish kerak?
      Dastur ishlayotganda xatoliklar chiqishi mumkin (masalan: noto‘g‘ri bo‘linish,
      mavjud bo‘lmagan o‘zgaruvchiga murojaat qilish, serverdan javob kelmasligi va h.k.).

      Agar bu xatolarni ushlab qolmasak, dastur to‘xtab qoladi yoki foydalanuvchi
      noto‘g‘ri natija ko‘radi.

    2. Misol bilan tushuntirish try catch finally

               try {
         // xavfli kod
      } catch (error) {
         // xatoni ushlaydi
       } finally {
         // doim bajariladi (hatto xato bo‘lsa ham)
       }

    3. Masalada ishlatilishini korish.

               try {
         let a = 10;
        let b = a + 5;
          console.log(b);
        } catch (err) {
          console.log("Xato:", err.message);
        } finally {
          console.log("Bu yer doim ishlaydi ✅");
        }

    4. 💥 throw - o‘zing Error chiqar! throw yordamida Error o‘zingiz qo‘lda chiqarishingiz mumkin.

      Masalan:

              let age = -5;

            try {
              if (age < 0) {
                throw new Error("Yosh manfiy bo‘lishi mumkin emas!");
              }
              console.log("Yosh:", age);
            } catch (err) {
              console.log("❌ Xatolik:", err.message);
            }
