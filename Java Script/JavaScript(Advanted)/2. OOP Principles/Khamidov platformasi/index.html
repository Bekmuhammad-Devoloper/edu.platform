  • Inheritance (meros olish)

    1. 🔰 Ta’rif:
      Inheritance (meros olish) — bu bir klass (child/avlod) boshqa klassdan (parent/ota-ona) xususiyat va metodlarni olishidir.


    2. ✅ extends — texnik vosita JavaScript’da extends — bu child klassni parent klassdan meros qilish uchun ishlatiladi.


      Namuna: 

                                  class Animal {
                            eat() {
                                console.log("Hayvon ovqatlanmoqda");
                            }
                            }
                            
                            class Dog extends Animal {
                                bark() {
                                console.log("Vov-vov");
                                }
                            }
                            
                            const dog = new Dog();
                            dog.eat();  
                            dog.bark();

    3. ✅ super — ota-ona klassga murojaat

      📌 Nima qiladi?
      super() bu — ota klassning constructor'ini chaqiradi
      Farzand klassda constructor yozilgan bo‘lsa, super() chaqirilishi majburiy

      Namuna: 

                                      class Animal {
                                    constructor(name) {
                                        this.name = name;
                                    }
                                }
                                
                                class Dog extends Animal {
                                    constructor(name, breed) {
                                     super(name); // super orqali Animal constructori chaqirilyapti
                                        this.breed = breed;
                                    }
                                
                                    info() {
                                    console.log(`${this.name} - bu ${this.breed} zotidagi it.`);
                                    }
                                }
                                
                                const myDog = new Dog("Sharik", "Ovcharka");
                                 myDog.info(); // Sharik - bu Ovcharka zotidagi it.

  • Polymorphism (polimorfizm)

    1. Polymorphism - (Poly kop, Morph shakl,qiyofa) Yani, "Bir narsa bir nechta shaklga ega" degan manoni beradi.

    2. Method Overriding — Polymorphism'ning yuragi

      🎯 Ta’rif: Farzand klass, ota klassdagi metodni o‘zicha qayta yozsa, bu method overriding bo‘ladi.

      Namuna: 

                                      class Animal {
                                    speak() {
                                    console.log("Hayvon tovush chiqaryapti");
                                    }
                                }
                                
                                class Dog extends Animal {
                                    speak() {
                                    console.log("It: vov-vov");
                                    }
                                }
                                
                                class Cat extends Animal {
                                    speak() {
                                    console.log("Mushuk: miyov-miyov");
                                    }
                                }
                                
                                let animals = [new Dog(), new Cat()];
                                animals.forEach(a => a.speak());

    3. Super bilan ota klass metodini saqlab qolish

      Agar siz ota klass metodini ham bajarib, ustiga qo‘shmoqchi bo‘lsangiz:

      Namuna: 

                                      class Animal {
                                    speak() {
                                    console.log("Hayvon tovush chiqaryapti");
                                    }
                                }
                                
                                class Parrot extends Animal {
                                    speak() {
                                    super.speak(); // ota klassdagi metodni ham chaqiradi
                                    console.log("Tutu: qiq-qiq!");
                                    }
                                }
                                
                                const bird = new Parrot();
                                bird.speak();

    4. Abstraksiya + Polymorphism kuchli juftlik

      Namuna: 

                                      class Employee {

  • Encapsulation (inkapsulyatsiya)

    1. 🧠 Ta’rif (oddiy tilda):
      Encapsulation — bu obyektning ichki ma'lumotlarini yashirish va ularni faqat maxsus
      metodlar orqali boshqarish.

    2. 🧃 Tasavvur qiling: sharbatsiz plastik butilka bor:
      Ichida sharbat (ma’lumot) bor.
      Siz uni qopqog‘ini ochmasdan to‘g‘ridan-to‘g‘ri sharbatni icha olmaysiz.
      Siz faqat qopqog‘i orqali ichishingiz mumkin.

    3. 🔐 Maxfiy (private) property:
      JavaScript ES2022 dan boshlab # orqali private property yaratish imkonini beradi.

      Namuna: 

                                          class BankAccount {
                                        #balance = 0; 
                                
                                        deposit(amount) {
                                        if (amount > 0) {
                                        this.#balance += amount;
                                        }
                                    }
                                
                                    getBalance() {
                                        return this.#balance;
                                        }
                                }
                                
                                const acc = new BankAccount();
                                acc.deposit(100);
                                console.log(acc.getBalance()); // ✅ 100
                                console.log(acc.#balance);     // ❌ Xatolik: private o‘zgaruvchi

    4. Getter va Setter metodlari
      Agar siz private property yaratgan bo‘lsangiz, unga faqat getter/setter metodlar orqali
      murojaat qilasiz.

      Namuna: 

                                          class User {
                                        #password;
                                        
                                        constructor(username, password) {
                                        this.username = username;
                                        this.#password = password;
                                        }
                                        
                                        getPassword() {
                                            return '******';
                                            }
                                    
                                        setPassword(newPass) {
                                            if (newPass.length >= 6) {
                                            this.#password = newPass;
                                            } else {
                                            console.log("Parol juda qisqa!");
                                                }
                                            }
                                        }
                                        
                                        const user = new User("bekmuhammad", "123456");
                                        console.log(user.getPassword()); 
                                    
                                        user.setPassword("123");   
                                        user.setPassword("abcdef");

  • Abstraction (abstraksiya)

    1. Abstraction — bu murakkab tizimdagi faqat muhim tafsilotlarni ko‘rsatish va keraksiz detallarni yashirishdir.

      Hayotiy misol

      Siz televizor pultidagi power tugmasini bosasiz — ichida nima bo‘layotgani sizga ahamiyatli emas. Faqat “TV yoqildi” desangiz bo‘ldi.

                                              class TV {
                                            #isPowered = false; 
                                    
                                        turnOn() {
                                            this.#connectToPower();
                                            this.#loadSystem();
                                            this.#showDisplay();
                                            console.log("TV yoqildi ✅");
                                            }
                                    
                                         // Quyidagilar abstraction qilingan (yashirilgan):
                                            #connectToPower() {
                                            console.log("Quvvat ulanmoqda...");
                                            }
                                    
                                            #loadSystem() {
                                            console.log("Sistema yuklanmoqda...");
                                            }
                                    
                                            #showDisplay() {
                                            console.log("Ekran yondi...");
                                            }
                                        }
                                    
                                            const tv = new TV();
                                            tv.turnOn(); // Faqat turnOn orqali TV yoqiladi
