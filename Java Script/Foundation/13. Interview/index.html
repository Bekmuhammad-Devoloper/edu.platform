Foundation

  • Og'zaki intervyu: tartib va maslahatlar

    Intervyu — 15–20 daqiqalik og'zaki suhbat. O'qituvchi har darsdan 1–2 ta savol beradi (quyida barcha darslarning savollari yig'ilgan) va bitta kichik algoritmni og'zaki tuzishni so'raydi.

    • Javobni ta'rif + misol shaklida bering: "while — oldindan shartli sikl. Masalan, parol to'g'ri kiritilguncha so'rash."
    • Bilmasangiz — taxmin qilmang, "bilmayman, lekin mantiqan ..." deb fikrlang.
    • Algoritmni og'zaki aytganda qadamlarni raqamlab gapiring.
    • Texnik so'zlarni inglizcha ham biling: variable, condition, loop, iteration, tag, attribute, selector.
