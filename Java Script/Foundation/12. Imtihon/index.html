  • Namunaviy variant

    1-qism: Test (namuna)

    1. 1 KB necha bayt? a) 1000 b) 1024 c) 8 d) 512
    2. Blok-sxemada romb nimani bildiradi? a) amal b) kiritish c) shart d) boshlanish
    3. Qaysi sikl kamida bir marta bajariladi? a) for b) while c) do-while d) hech biri
    4. Qaysi teg abzats uchun? a) <a> b) <p> c) <h1> d) <div>
    5. padding nima? a) tashqi masofa b) ichki masofa c) chegara d) kenglik

    2-qism: Algoritm

    1. Chiziqli: Besh xonali sonning birinchi va oxirgi raqamlari o'rnini almashtiring: 12345 → 52341.
    2. Shartli: Uchta son kiritiladi — ularni o'sish tartibida chiqaring (faqat shartlar bilan).
    3. Siklik: N ta son kiritiladi. Musbatlar yig'indisi, manfiylar soni va eng kattasini chiqaring. Kuzatuv jadvali: 3, -1, 7, -4, 2.

    3-qism: Debug
