  • Parametrli sikl (for)

    for — takrorlanishlar soni oldindan ma'lum bo'lganda ishlatiladigan sikl. Boshlang'ich qiymat, shart va qadam bitta qatorda yoziladi.

    Psevdokod:                         JavaScript (keyingi modulda):
UCHUN i = 1 DAN 10 GACHA           for (let i = 1; i <= 10; i++) {
   CHIQAR i                            console.log(i);
TAMOM                              }

    Qanday ishlaydi

    1. i = 1 — bir marta, boshida.
    2. Shart i <= 10 tekshiriladi: rost → tana bajariladi; yolg'on → sikl tugaydi.
    3. Tana bajarilgach, qadam: i = i + 1.
    4. 2-qadamga qaytiladi.

    Qadam turlari

    UCHUN i = 0 DAN 20 GACHA QADAM 2     -> 0 2 4 ... 20   (juft sonlar)
UCHUN i = 10 DAN 1 GACHA QADAM -1    -> 10 9 8 ... 1   (teskari)
UCHUN i = 1 DAN n GACHA              -> n marta

    Tipik masalalar va "shablonlar"

    // 1) Yig'indi 1..n
s = 0
UCHUN i = 1 DAN n GACHA
   s = s + i
TAMOM

// 2) Faktorial n!
p = 1
UCHUN i = 1 DAN n GACHA
   p = p * i
TAMOM

// 3) Sanash (nechta juft son?)
k = 0
UCHUN i = 1 DAN n GACHA
   AGAR i mod 2 == 0 BO'LSA k = k + 1
TAMOM

// 4) Eng katta (maksimum) — n ta son kiritiladi
KIRIT x
max = x
UCHUN i = 2 DAN n GACHA
   KIRIT x
   AGAR x > max BO'LSA max = x
TAMOM

    Ichma-ich (nested) sikl

    UCHUN i = 1 DAN 3 GACHA          natija:
   UCHUN j = 1 DAN 3 GACHA       1 2 3
      CHIQAR i * j               2 4 6
   TAMOM                         3 6 9
TAMOM
Ichki sikl tashqi siklning har bir qadamida to'liq bajariladi: 3 * 3 = 9 marta.

    Kuzatuv jadvali (faktorial, n = 4)

    i | p
--+----
  | 1
1 | 1
2 | 2
3 | 6
4 | 24   -> CHIQAR 24

  • Interview savollari

    1. 1. for sikli qachon ishlatiladi?

      Javobni ko'rish

      Takrorlanishlar soni oldindan ma'lum bo'lganda.

    2. 2. for siklining bajarilish tartibi?

      Javobni ko'rish

      Boshlang'ich qiymat (1 marta) → shart → tana → qadam → shart → ...

    3. 3. UCHUN i = 1 DAN 10 GACHA tanasi necha marta bajariladi?

      Javobni ko'rish

      10 marta.

    4. 4. Ichma-ich siklda ichki tana necha marta bajariladi?

      Javobni ko'rish

      Tashqi takrorlar soni × ichki takrorlar soni (3 × 3 = 9).

    5. 5. Faktorial uchun yig'uvchi nimadan boshlanadi? Nega?

      Javobni ko'rish

      1 dan — chunki 0 ga ko'paytirsak hamma narsa 0 bo'ladi.

    6. 6. Sonning raqamlari yig'indisini qanday topamiz?

      Javobni ko'rish

      Sikl: s = s + n mod 10; n = n div 10; toki n > 0.

    7. 7. Teskari sanash uchun nima o'zgaradi?

      Javobni ko'rish

      Boshlang'ich qiymat katta, shart i >= 1, qadam -1.
