Foundation

  • CSS asoslari

    CSS (Cascading Style Sheets) — sahifaning ko'rinishini belgilaydi: ranglar, shriftlar, o'lchamlar, joylashuv. HTML — skelet, CSS — kiyim va dizayn.

    CSS ni qo'shish usullari

    1) Inline (tegning ichida):      <p style="color: red;">...</p>
2) Internal (head ichida):       <style> p { color: red; } </style>
3) External (alohida fayl) ✅:   <link rel="stylesheet" href="style.css">

    Sintaksis

    selektor {
  xususiyat: qiymat;
  xususiyat: qiymat;
}

h1 { color: #14c7d7; font-size: 32px; }

    Selektorlar

    p            teg selektori        barcha <p>
.card        class selektori      class="card" (ko'p marta ishlatiladi)
#header      id selektori         id="header" (sahifada 1 ta)
*            universal            hammasi
div p        avlod (descendant)   div ichidagi barcha p
a:hover      holat (pseudo-class) sichqoncha ustida turganda
h1, h2       guruh                ikkalasi ham

    Box model (quti modeli) — eng muhim tushuncha

    +---------------------------- margin (tashqi masofa) ----+
|  +----------------------- border (chegara) ---------+  |
|  |  +------------------ padding (ichki masofa) --+  |  |
|  |  |                                             |  |  |
|  |  |              content (width x height)       |  |  |
|  |  |                                             |  |  |
|  |  +---------------------------------------------+  |  |
|  +---------------------------------------------------+  |
+---------------------------------------------------------+

.card {
  width: 300px;
  padding: 20px;              /* ichki */
  border: 2px solid #ccc;     /* chegara */
  margin: 10px auto;          /* tashqi; auto — markazlash */
  border-radius: 12px;        /* burchaklarni yumaloqlash */
  box-sizing: border-box;     /* width ga padding va border kiradi */
}
margin: 10px 20px;         -> yuqori/past 10, chap/o'ng 20
margin: 5px 10px 15px 20px; -> yuqori, o'ng, past, chap (soat strelkasi)

    display

    Flexbox asoslari

    .container {
  display: flex;                 /* bolalarni qatorga teradi */
  justify-content: space-between;/* gorizontal: flex-start | center | space-between | space-around */
  align-items: center;           /* vertikal: flex-start | center | flex-end */
  gap: 16px;                     /* elementlar orasidagi masofa */

    Kaskad va ustuvorlik

    Bir elementga bir nechta qoida tegsa: inline > id > class > teg; teng bo'lsa — keyin yozilgani g'olib. !important — eng kuchli, lekin iloji boricha ishlatmang.

  • Amaliyot

    Har bir masalani avval daftarda (so'z bilan, blok-sxema yoki psevdokod) yeching, keyin kuzatuv jadvali bilan tekshiring.

    1. CSS ulash

      «Men haqimda» sahifasiga style.css ulang. body ga shrift va fon rangi, h1 ga rang va markazlash bering.

    2. Uch usul

      Bitta p ga rangni inline, internal va external usulda bering. Qaysi biri g'olib bo'ladi?

    3. Ranglar

      Bir xil qizil rangni nom, hex, rgb va rgba (yarim shaffof) ko'rinishida yozing.

    4. Matn

      Abzatsga: shrift o'lchami 18px, qator balandligi 1.6, rang kulrang, matn markazda.

    5. Class va id

      3 ta p yarating: biriga .muhim class, biriga #asosiy id bering va turli rang qo'ying.

    6. Hover

      Havola ustiga sichqoncha kelganda rangi o'zgarsin va tagidagi chiziq yo'qolsin.

    7. Box model

      3 ta .box div: 150×150px, turli fon, padding 20px, border 3px, margin 10px. DevTools da box modelni ko'ring.

    8. Kartochka

      Mahsulot kartochkasi: rasm, nomi, narxi, «Sotib olish» tugmasi. 280px kenglik, soya, burchaklar yumaloq, hover da ko'tarilsin.

    9. Navbar

      header ichida logo (chapda) va 4 ta havola (o'ngda) — flexbox, justify-content: space-between.

    10. 3 kartochka

      Kartochkadan 3 ta qiling va flex konteynerda joylang: gap 20px, markazda, flex-wrap: wrap.

    11. Selektorlar

      p — kulrang; .muhim — qizil va qalin; #sarlavha — 40px; ul li — markersiz; a:hover — tagiga chiziq.

    12. Ustuvorlik

      Element teg, class, id va inline uslub bilan bir vaqtda bo'yalgan. Qaysi rang chiqadi? Har birini ketma-ket olib tashlab tekshiring.

    13. Markazlash

      Ekran o'rtasida (vertikal va gorizontal) turadigan 300×200px blok yasang — flexbox bilan.

    14. Hero bo'lim

      To'liq ekran balandligidagi hero: fon rasmi, ustida qoraytirish qatlami, markazda sarlavha va 2 ta tugma.

    15. Responsive

      @media (max-width: 600px) da kartochkalar ustun bo'lib tushsin, navbar havolalari kichraysin.

    16. CSS o'zgaruvchilar

      Barcha ranglarni :root dagi o'zgaruvchilarga o'tkazing va bitta o'zgaruvchini almashtirib butun sahifa rangini o'zgartiring.

  • Uyga vazifa

    Barcha masalalarni ketma-ket bajaring. Oxirgi masalalar qo'shimcha ball uchun.

    1. Rangli sahifa

      «Men haqimda» sahifasini 3 ta rang va 1 ta shrift bilan bezang.

    2. Tugmalar

      3 xil uslubdagi tugma: to'ldirilgan, chegarali, yumaloq. Hammasida hover bo'lsin.

    3. Ro'yxat bezagi

      ul markerlarini olib tashlang va har bir li ga fon, padding va chegara bering.

    4. Rasm

      Rasmni yumaloq qiling (border-radius: 50%) va soya bering.

    5. Jadval bezagi

      Dars jadvalingizga chegara, sarlavha qatori uchun fon va qatorlar hover ini qo'shing.

    6. Landing sahifa

      header (logo + nav), hero (sarlavha, matn, tugma), «Xizmatlar» — 3 ta kartochka (flex), «Biz haqimizda» — matn + rasm yonma-yon, footer.

    7. Forma bezagi

      Ro'yxatdan o'tish formasini bezang: inputlar to'liq kenglikda, :focus da chegara rangi o'zgarsin.

    8. Galereya

      6 ta rasmni flex bilan 3 tadan 2 qatorga joylang, hover da biroz kattalashsin (transform: scale).

    9. Narxlar

      3 ta tarif kartochkasi; o'rtadagisi «Eng ommabop» belgisi bilan ajralib tursin.

    10. Footer

      4 ustunli footer: kompaniya haqida, havolalar, aloqa, ijtimoiy tarmoqlar.

    11. Talaba kundaligi

      To'liq sahifa: profil (rasm + ma'lumot), dars jadvali, baholar kartochkalari (90+ yashil, 60 dan past qizil chegara), aloqa formasi, footer.

    12. Mobil versiya

      Landing sahifangizni 375px kenglikda chiroyli ko'rinadigan qiling: navbar, hero va kartochkalar.

    13. Animatsiya

      Tugma va kartochkalarga transition qo'shing; hero sarlavhasiga @keyframes bilan paydo bo'lish animatsiyasi bering.

    14. Maket bo'yicha

      Istalgan mashhur saytning bosh sahifasidan bir qismini (header + hero) HTML/CSS bilan takrorlang.

  • Interview savollari

    1. 1. CSS nima va HTML dan farqi?

      Javobni ko'rish

      CSS — ko'rinish (uslub); HTML — tuzilma (kontent).

    2. 2. CSS ni ulashning 3 usuli? Qaysi biri tavsiya etiladi?

      Javobni ko'rish

      Inline, internal, external. External (alohida fayl) — qayta ishlatish va tartib uchun.

    3. 3. class va id farqi?

      Javobni ko'rish

      class — ko'p elementga, bir elementda bir nechta bo'lishi mumkin; id — sahifada yagona.

    4. 4. Box model nima?

      Javobni ko'rish

      Element: content + padding + border + margin. box-sizing: border-box bilan width ga padding va border kiradi.

    5. 5. margin va padding farqi?

      Javobni ko'rish

      padding — chegara ichidagi masofa; margin — chegaradan tashqaridagi masofa.

    6. 6. display: block, inline, inline-block farqi?

      Javobni ko'rish

      block — yangi qator, to'liq kenglik; inline — matn ichida, width ishlamaydi; inline-block — matn ichida, width/height ishlaydi.

    7. 7. Flexbox nima uchun? justify-content va align-items farqi?

      Javobni ko'rish

      Elementlarni qator/ustunda moslashuvchan joylashtirish. justify-content — asosiy o'q bo'ylab (gorizontal), align-items — ko'ndalang o'q (vertikal).

    8. 8. Selektorlar ustuvorligi?

      Javobni ko'rish

      inline > id > class > teg; teng bo'lsa keyingisi g'olib; !important eng kuchli.

    9. 9. :hover nima?

      Javobni ko'rish

      Sichqoncha element ustida turganda qo'llanadigan pseudo-class.
