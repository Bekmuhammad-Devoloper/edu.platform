  • Shartli sikllar: while va do-while

    Takrorlanishlar soni oldindan noma'lum bo'lsa — shartli sikllar ishlatiladi: sikl shart rost bo'lguncha davom etadi.

    while — oldindan shartli sikl

    Psevdokod:                      JavaScript:
TOKI shart BO'LSA               while (shart) {
   tana                            // tana
TAMOM                           }
Shart AVVAL tekshiriladi: yolg'on bo'lsa tana umuman bajarilmaydi (0 marta).

    do-while — keyin shartli sikl

    Psevdokod:                      JavaScript:
BAJAR                           do {
   tana                            // tana
TOKI shart BO'LSA               } while (shart);
Tana AVVAL bajariladi, keyin shart tekshiriladi: kamida 1 marta bajariladi.

    Qaysi birini tanlash?

    for       - takrorlar soni ma'lum:          1 dan n gacha
while     - soni noma'lum, avval tekshirish: fayl tugaguncha o'qi
do-while  - kamida 1 marta kerak:            menyu ko'rsat, to'g'ri javob kelguncha so'ra

    Misol 1: parol (do-while)

    BAJAR
   KIRIT parol
   AGAR parol != "bek123" BO'LSA CHIQAR "Qayta urinib ko'ring"
TOKI parol != "bek123" BO'LSA
CHIQAR "Xush kelibsiz!"

    Misol 2: raqamlar soni (while)

    KIRIT n          // 48213
k = 0
TOKI n > 0 BO'LSA
   k = k + 1
   n = n div 10
TAMOM
CHIQAR k         // 5

    Misol 3: Evklid algoritmi — EKUB

    KIRIT a, b       // 48, 18
TOKI b != 0 BO'LSA
   r = a mod b
   a = b
   b = r
TAMOM
CHIQAR a         // 6

Kuzatuv: (48,18) -> (18,12) -> (12,6) -> (6,0) -> EKUB = 6

    break va continue (tushuncha)

    • break — siklni darhol to'xtatish (masalan, kerakli son topilganda).
    • continue — joriy takrorni o'tkazib yuborib, keyingisiga o'tish.

    Bayroq (flag) o'zgaruvchi

    topildi = yolg'on
TOKI (EMAS topildi) VA (i <= n) BO'LSA
   AGAR massiv[i] == x BO'LSA topildi = rost
   i = i + 1
TAMOM

  • Interview savollari

    1. 1. while va do-while farqi?

      Javobni ko'rish

      while — shart avval tekshiriladi (0 marta bajarilishi mumkin); do-while — tana avval bajariladi (kamida 1 marta).

    2. 2. Qachon for, qachon while?

      Javobni ko'rish

      for — takrorlar soni ma'lum; while — noma'lum, shartga bog'liq.

    3. 3. break va continue nima?

      Javobni ko'rish

      break — siklni to'xtatadi; continue — joriy takrorni o'tkazib yuboradi.

    4. 4. Evklid algoritmi nima?

      Javobni ko'rish

      EKUB topish: toki b != 0: (a, b) = (b, a mod b); javob a.

    5. 5. Bayroq (flag) o'zgaruvchi nima uchun?

      Javobni ko'rish

      Biror hodisa yuz berganini (topildi/topilmadi) eslab qolish uchun.

    6. 6. Sonni teskari yozish algoritmi?

      Javobni ko'rish

      r = 0; toki n > 0: r = r*10 + n mod 10; n = n div 10.
